# 국내 우선 자료조사 절차

시행: 2026-09-21 사용자 명시 지시
적용: 강의자료 신규 조사·내용 보강·PPT 구성안·대본 작성
상태: REQUIRED — `PPT_WORKFLOW.md`의 자료조사 단계에서 적용한다.

## 1. 필수 순서

**국내 자료, 보도·기사, 정부발표자료를 우선 최대한 조사하라. 국내 조사 결과와 남는 질문을 정리한 뒤 국외 자료를 조사하라.**

1. 현재 프로젝트·대화·Git에 있는 기준본과 수집자료를 확인한다.
2. 국내 법·제도·공식통계·정책 및 정부발표를 조사한다.
3. 국내 학술논문·연구보고서·실태조사와 보도·기사·현장취재·인터뷰를 충분히 조사한다. 2와 3은 국내 조사 단계 안에서 병행할 수 있다.
4. 국내 자료로 확인한 내용, 엇갈린 내용, 아직 확인하지 못한 질문을 표로 정리한다.
5. 그 질문에 대응하는 국외 원자료·사례·연구를 찾는다.
6. 국내 기준선과 국외 비교조건을 맞춘 뒤 본편·보충·대본의 위치를 정한다.

이 순서는 ‘국내 자료 몇 개를 장식적으로 넣은 뒤 외국 논문 중심으로 만든다’는 방식과 다르다. 유명한 국외 실험이나 메타분석부터 목차를 채우지 않는다. 이미 확보한 국외 자료는 보존하되 국내 조사 전에 그것을 본편 중심축으로 확정하지 않는다.

## 2. 조사 전에 고정할 질문

- 논제의 대상은 누구인가? 나이·사건·정책수혜자 범위를 적는다.
- 어떤 행위와 정책을 비교하는가? 투약·소지·판매, 구금·형 선고·보호처분 등 서로 다른 것을 섞지 않는다.
- 바꾸려는 것은 법적 허용 여부, 기본 처리경로, 적용대상, 개입 강도, 예산배분 가운데 무엇인가?
- 무엇이 판단 자료가 되는가? 책임·권리, 규모, 실제 운영, 효과, 비용, 당사자 경험을 구별한다.
- 이미 앞 슬라이드에서 답한 질문과 이번에 새로 채워야 할 질문은 무엇인가?

## 3. 국내 조사처 — 논제에 맞는 곳을 골라 실제로 확인한다

아래는 점검할 채널의 예시다. 기관별 사이트가 존재한다는 사실만으로 조사 완료로 처리하지 않는다. 한글 문헌이라도 외국 대상 연구를 소개한 것이면 ‘국내 대상 효과자료’라고 분류하지 않는다.

| 자료 역할 | 우선 확인할 국내 채널 예시 | 확인할 내용 |
|---|---|---|
| 법령·판례·절차 | 국가법령정보센터, 법원·헌법재판소 공개자료, 소관 부처 행정규칙·업무안내 | 적용 시점, 대상, 주체, 요건, 가능한 결과 |
| 규모·처리통계 | KOSIS, 경찰청, 대검찰청, 법원행정처, 소관 부처 연보·백서·통계보고서 | 원표·주석, 인원/건수, 집계단계, 기간, 연령, 분모 |
| 정부의 실제 대응 | 부처·지자체 보도자료, 시행계획, 업무보고, 예산·결산·성과평가, 시범사업 결과 | 계획/시행/실적/효과의 구분, 담당기관·인력·이용경로 |
| 연구·조사 | KICJ, NYPI 등 관련 연구기관, NKIS, PRISM, RISS, KCI, 국회입법조사처·예산정책처·정책토론회 | 질문지·표본·분석대상·실제 결과·저자의 해석 |
| 국내 실제 사례 | 전국·지역 언론, 공영방송·통신사, 후속취재·탐사보도·현장 인터뷰 | 사건 경과, 적용된 조치, 당사자 경험, 반복·누락·연결 공백 |
| 현장 실행 | 관련 공공기관·전문기관의 프로그램 매뉴얼, 연차보고서, 사업평가, 이용 안내 | 누가 실제 무엇을 제공하며 언제 시작·완료되는가 |

이 목록을 모든 주차에 기계적으로 전부 검색하지는 않는다. 대신 해당 논제와 관련된 역할을 하나도 확인하지 않은 채 ‘국내 자료 없음’으로 넘어가지 않는다.

## 4. 검색 방식

### 4-1. 하나의 단어로 끝내지 않는다

논제 핵심어에 다음 표현을 결합하고 동의어·제도명·과거 명칭·연도도 바꿔 조사한다.

- 규모: 실태, 현황, 통계, 백서, 연보, 연령별, 죄명별, 처리결과
- 실제 제도: 시행계획, 운영지침, 매뉴얼, 사업평가, 시범사업, 보도자료, 예산, 결산
- 현장: 사례, 인터뷰, 수사관, 상담사, 보호자, 당사자, 법원 판단, 후속 보도
- 효과: 재사용, 재범, 재체포, 치료 효과, 참여, 중도탈락, 완료, 사후관리
- 비용·권리: 접근성, 대기, 지역 격차, 비용, 인력, 자유 제한, 절차보장

검색어는 예시일 뿐 결과를 찾았다는 증거가 아니다. 실제 검색일·채널·결과를 남긴다.

### 4-2. 연결된 원문을 따라간다

기사에 ‘정부 제출자료’, ‘연구원 보고서’, ‘법원 판결’이 나오면 그 생산기관과 원자료를 찾아 대조한다. 정부 발표가 원표를 첨부하면 본문과 주석을 함께 읽는다. 보고서에서 유용한 연구를 인용하면 해당 연구의 원문까지 확인한다.

원문을 확보하지 못한 경우, 기사를 실제로 읽었다면 ‘보도에 따르면’의 수준으로 사용할 수 있다. 그러나 ‘정부 원표 확인’, ‘판결문 직접 확인’으로 출처 상태를 승격하지 않는다.

### 4-3. 실제 열람 범위와 접근 실패 처리

자료의 신뢰성·논제 직접성과 **실제 열람 범위**를 별도로 기록한다. 자료대장의 ‘실제 확인 범위’에는 아래 상태와 읽은 쪽·절을 함께 쓴다.

| 상태 | 실제로 확인한 범위 |
|---|---|
| 원문 확인 | 원문에서 사용할 주장·표·관련 방법과 결론을 직접 대조함. 전문 통독 여부도 별도로 밝힘 |
| 원문 일부 확인 | 원문의 특정 쪽·절만 읽음. 확인하지 않은 범위를 함께 적음 |
| 초록·목차·2차 자료 확인 | 초록, 목차 또는 다른 글의 요약을 읽음. 무엇을 읽었는지 특정함 |
| 검색 색인·발췌만 확인 | 검색 결과에 잡힌 문구만 확인함 |
| 서지·링크만 확보 | 문서의 존재·주소만 확인함. 내용 검증 전 |

- 상태는 문서 하나에 일괄 부여하지 않아도 된다. 같은 문서의 날짜는 확인했어도 인용한 숫자·논거는 미확인일 수 있으므로 필요한 주장을 각각 대조한다(§8-3).
- 공개 원문, 발행기관의 다른 저장소, 학술지·저자 공개본, 공식 첨부파일 등 적절한 대체 경로를 먼저 시도한다. 로그인·유료·403·깨진 링크는 접근 실패로 기록하고 자료가 없다는 결론으로 바꾸지 않는다.
- 확인 가능한 항목부터 처리하고, 미해결 항목은 **문서명·직접 링크 또는 공식 상세 페이지·필요한 쪽/절·아직 확인할 문장**을 제공한다. 접근하지 못한 문헌을 ‘원문 확인 완료’로 표시하지 않는다. 사용자에게 파일을 요청해야 하면 끝내 남은 자료만 특정한다.

## 5. 국내 보도·기사의 사용 규칙

- 기사·인터뷰를 단순한 흥미 자료로만 취급하지 않는다. 실제 행위의 경과, 도움요청 실패, 업무의 공백, 제도 선택의 이유를 보여줄 수 있다.
- 기자의 설명, 수사·행정기관의 발표, 피의자·피해자·상담자의 진술, 법원의 판단을 구별한다.
- 수사 발표와 확정 판결을 구별한다. 후속 선고·상소·정정이 있으면 함께 확인한다.
- 면접 사례 몇 건으로 ‘대부분’, ‘가능성이 높다’, ‘항상’이라는 빈도·인과 주장을 만들지 않는다.
- 보도에서 다룬 예외적으로 중대한 사건이 논제의 정책대상에 포함되는지 확인한다.
- 확인된 사건 내용과 강의자가 설명하기 위해 구성한 가상 예시를 혼용하지 않는다.
- 국내 사례는 불필요한 실행 수법이 아니라 정책 판단에 필요한 경위·결과·제도 반응을 중심으로 정리한다.
- 피해 뒤 생활의 어려움을 보여줄 사례는 인터뷰·후속 보도에서 실제 어려움과 시점을 확인한다. 학교생활이라면 등교·결석·수업 참여·생활공간 이용·가해학생과의 접촉 등 원문이 확인한 경험을 적는다. 폭력이 발생했다는 사실만으로 그 결과를 추정하지 않는다.

### 5-1. 수업용 영상과 링크 재전달

영상 자료에는 `고정 ID / 제목 / 매체·게시일 / 직접 재생 링크 / 전체 길이 / 사용할 구간 / 다루는 사실·수업 목적 / 확인 상태`를 기록한다. 이 기준은 국외 영상에도 적용한다.

- 방송사·공식 채널의 재생 페이지를 우선하고, 필요하면 기사 본문 링크를 함께 남긴다. 제목·사건·링크가 실제로 일치하는지 확인한다.
- 전체 길이와 사용할 구간의 길이를 구별한다. 시간을 확인하지 못했으면 ‘길이 미확인’으로 적으며 검색 요약이나 기사 분량으로 추정하지 않는다.
- 같은 사건을 다룬 서로 다른 영상은 별개 ID로 둔다. 등록 주소 불일치, 실제 거주지, 전입·이사 절차 등 보도가 확인한 문제를 정확히 구분한다.
- 사용자가 ‘2번 링크’, ‘주소로’, ‘다시’라고 하면 앞서 제공한 번호와 영상의 대응을 유지하고 해당 링크를 바로 준다. 후보를 재정렬할 때는 기존 ID를 보존한다.

## 6. 국외 조사로 넘어가는 게이트

다음 네 가지를 짧은 자료대장으로 제시한 뒤 국외 자료를 조사한다.

1. **국내에서 찾은 것:** 핵심 법·제도, 통계, 사건·현장, 연구·실행자료가 무엇인가.
2. **국내에서 아직 답하지 못한 것:** 원하는 대상·비교경로·효과·기간·지표 중 무엇이 비어 있는가.
3. **찾아본 범위:** 관련 기관·문헌DB·언론, 검색어 변형, 연도, 연결 원문을 어느 정도 확인했는가.
4. **외국 자료가 필요한 이유:** 동일 정책 효과, 비교제도, 특정 치료구성, 장기결과, 비용 등 어떤 질문을 보완하는가.

몇 번의 검색만으로 ‘국내에는 없다’고 선언하지 않는다. 반대로 끝없이 조사했다는 선언도 하지 않는다. 관련 채널과 원문을 확인해 새로운 유효 자료의 추가가 제한적이면 조사 범위와 남은 공백을 남기고 다음 단계로 간다. 접근 제한·검색 오류는 자료 부재와 구분한다.

사용자가 특정 국외 자료를 직접 지정하거나 즉시 비교를 요청한 경우에는 그 요청을 우선한다. 이때도 국내 기준선에 대한 확인 상태를 명시한다. 새 과제마다 국내 조사를 처음부터 반복할 필요는 없으며, 확인된 자료대장을 재사용하되 변경 가능성이 있는 법·정책·통계는 갱신한다.

## 7. 국외 자료의 역할과 확인사항

국외 자료는 국내 빈칸을 아무 연구로 채우는 용도가 아니다. 각 자료에 필요한 이유를 하나씩 적는다.

- 대상 연령·위험도·문제 수준이 국내 논제와 맞는가?
- 실제 바꾼 것이 형사책임, 기소, 구금, 감독, 치료 구성 중 무엇인가?
- 비교집단도 치료·교육을 받았는가?
- 자기보고 사용, 검사 양성, 재체포, 재유죄, 수감, 교육, 비용 중 무엇을 측정했는가?
- 실제 서비스의 빈도·기간과 추적 시점은 무엇인가?
- 국내에 이미 있는 제도와 국외 비교제도가 어떻게 다른가?
- 이 자료는 정책의 직접 효과, 특정 개입의 효과, 작동 가능성, 규범적 비교 중 어디에 쓰이는가?

국외 자료를 늦게 조사한다는 것이 낮은 비중으로 반드시 배치한다는 뜻은 아니다. 직접적인 국외 평가가 국내의 간접자료보다 효과 질문에 더 적합하면 그 역할을 분명히 하여 사용한다. 반대 방향의 결과와 무효·불확실한 결과도 같은 기준으로 수집한다.

## 8. 자료대장 양식

### 8-1. 자료별 기록

| 필드 | 기록할 내용 |
|---|---|
| 자료 ID | 주차-국내/국외-일련번호 |
| 답할 질문 | 이 자료로 어떤 질문에 답하려는가 |
| 생산주체·서지 | 기관/저자, 문서명, 날짜, URL 또는 실제 파일명·페이지 |
| 실제 확인 범위 | 원문/원표/질문지/판결문/보도 본문/요약 중 무엇을 읽었는가 |
| 대상·단위·기간 | 인원/사건/검사, 분모, 지역·연령, 관찰 시점 |
| 실제 내용 | 절차, 개입과 비교경로, 결과 수치 또는 발언·판단 |
| 자료의 역할 | 기준선/현장사례/효과/운영/비용/권리/규범적 논증 |
| 논제와의 연결 | 어느 주장에 어떤 이유를 보태는가; 공통 조건인지도 기록 |
| 제한·공백 | 미확인 원문, 비교 불일치, 적용범위 등 |
| 배치 | 본편 필수 / 본편 확장 / 대본에서 언급 / 보충 자료 / 사용하지 않음 + 예정 단원·슬라이드 |
| 상태 | 사용/보류/중복/대체, 검증일 |

### 8-2. 국내 조사 후 외국 조사 질문표

| 남은 질문 | 확인한 국내 자료·조사 범위 | 부족한 부분 | 필요한 국외 자료의 조건 | 예정 위치 |
|---|---|---|---|---|
| 예: 종료 뒤 재사용이 줄었는가 | 실제로 읽은 국내 자료를 적음 | 같은 대상의 종료 뒤 비교가 부족 | 해당 연령, 실제 비교경로, 종료 뒤 측정 | 효과 단원 |

예시 행을 실제 조사 결과로 사용하지 않는다.

### 8-3. 주장별 원문 대조표

다음 필드를 기존 자료대장 또는 페이지 검수표에 추가한다. 같은 내용의 별도 표를 중복 작성하지 않는다.

| 실제 쪽·항목 | 확인할 문장·수치 | 원문·버전·쪽/절·링크 | 실제 열람 범위(§4-3) | 대조 결과 | 조치·남은 확인 |
|---|---|---|---|---|---|
|  |  |  |  | 일치 / 수정 필요 / 미확인 |  |

원문 쪽수와 PDF 뷰어 쪽수가 다르면 둘을 구별한다. ‘강사 원문 대조 전’ 표시가 있던 항목은 해당 문장·수치를 실제로 대조한 뒤에만 상태를 바꾼다. 초안에 있었거나 반복 인용됐다는 이유로 검증된 것으로 취급하지 않는다.

## 9. 완료 기준

- 국내 법·실제 처리·현장 경험을 확인한 뒤 외국 연구를 골랐는가?
- 보도·기사·정부발표자료를 직접 읽고 서로 어떤 종류의 근거인지 구별했는가?
- 계획·실적·효과를 구별했고, 원자료를 못 읽은 부분을 확인된 것처럼 쓰지 않았는가?
- 주장에 맞는 자료만 선별하지 않고 엇갈리는 결과도 보았는가?
- 각 국외 자료가 국내의 어떤 질문을 보완하는지 설명할 수 있는가?
- 국내·국외라는 구분과 자료의 신뢰성·직접성을 혼동하지 않았는가?
- 검색 로그와 출처가 남아 후속 제작자가 같은 자료를 확인할 수 있는가?

이 절차의 목적은 국내 자료의 개수를 형식적으로 늘리는 것이 아니라, **한국에서 지금 작동하는 제도와 실제 경험을 기준선으로 삼고 필요한 국외 근거를 연결하는 강의**를 만드는 것이다.
