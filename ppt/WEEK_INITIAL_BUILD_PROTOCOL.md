# 신규 주차 초기 설계 프로토콜 — 공개논의 → 쟁점 → 표적조사

시행: 2026-09-27 사용자 명시 지시  
적용: 경찰대학 「범죄·공공안전세미나Ⅱ」의 **신규 주차 강의자료를 처음 설계할 때**  
상태: REQUIRED — `PPT_WORKFLOW.md`, `DOMESTIC_FIRST_RESEARCH_PROTOCOL.md`, `WEEK_RESEARCH_COVERAGE_TEMPLATE.md`와 함께 적용한다.

## 0. 핵심 원칙

신규 주차는 **쟁점을 먼저 임의로 정하고 자료를 끼워 맞추는 방식**으로 시작하지 않는다. 반대로 자료유형 12개를 모두 같은 깊이로 먼저 파고 난 뒤 마지막에 쟁점을 억지로 만드는 방식도 피한다.

기본 순서는 다음과 같다.

> **① 논제 범위 고정 → ② 국내 공개논의·정책·사법자료 선행 스캔 → ③ 직접적인 국외 자료 보완 → ④ 5~7개 안팎의 잠정 쟁점 도출 → ⑤ 쟁점별 표적조사 → ⑥ 12개 자료영역·통계 5축 최종 점검 → ⑦ 최종 쟁점·목차·PPT 구성**

핵심은 **실제로 사회·정책·법정에서 무엇이 쟁점이 되었는지를 먼저 확인한 뒤, 그 쟁점을 검증할 자료를 추가로 찾는 것**이다.

쟁점 수 5~7개는 기본적인 실무 범위다. 논제가 단순하거나 복잡하면 더 적거나 많을 수 있으며, 숫자를 맞추기 위해 쟁점을 쪼개거나 합치지 않는다.

---

## 1. 0단계 — 논제와 기준선을 먼저 잠근다

자료 검색 전에 다음을 한 문장씩 적는다.

- 정식 논제
- 직접 대상
- 바꾸거나 선택하려는 제도·정책·처우
- 현행 기준선
- 비교대안
- 핵심 결과영역
- 논제 밖의 인접 문제

이 단계에서 **“무엇을 찬반 판단하는가”**가 분명하지 않으면 검색을 시작하지 않는다.

---

## 2. 1단계 — 국내 ‘쟁점 발견용’ 자료를 먼저 최대한 찾는다

### 2-1. 우선 확인할 국내 자료군

논제를 직접 다룬 자료를 가능한 범위에서 먼저 넓게 찾는다.

1. **공론화·숙의·공청회·국회토론회·정책포럼**
2. **정부·공공기관 정책브리핑·정책설명자료·업무보고**
3. **부처·경찰·법원·지자체·공공기관 보도자료**
4. **국가인권위원회·위원회·전문기관의 권고·의견·관계기관 회신**
5. **헌법재판소 결정문과 공개변론 자료**
6. **대법원·각급 법원의 판결문·결정문**
7. **경청회·간담회·공식 의견수렴**
8. **국회입법조사처·국회예산정책처·국책연구기관의 정책자료**
9. **전문기관·학계·현장단체가 참여한 공개토론·세미나·자료집**
10. **논제를 직접 다룬 국내 연구·실태조사·현장면접**
11. **제도 적용을 보여 주는 실제 국내 사건·사례·후속보도**

정확한 명칭과 절차성격을 보존한다. 토론회·경청회·권고·회신·공개변론·판결을 모두 ‘공론화’라고 부르지 않는다.

### 2-2. 각 자료에서 추출할 것

행사나 문서의 존재만 기록하지 않는다. 최소한 다음을 뽑는다.

- 누가 어떤 입장을 제시했는가
- 그 입장의 이유는 무엇인가
- 어떤 사례·통계·연구·법리를 근거로 들었는가
- 반대·경쟁 입장은 무엇이었는가
- 어떤 대안·보완책·실행조건을 제시했는가
- 합의·권고·결정이 있었는가, 아니면 의견제시에 그쳤는가
- 오늘 논제에서 어떤 판단질문을 남기는가
- 그 주장을 다시 확인해야 할 원자료는 무엇인가

### 2-3. 검색어 확장

논제명 하나로 끝내지 않는다.

- 현행 제도명·과거 제도명
- 관련 법률·조문
- 정책대안명
- 주요 기관명
- 핵심 행위·처분명
- 찬반 표현뿐 아니라 ‘개선 / 폐지 / 유지 / 보호 / 권리 / 효과 / 실태 / 운영 / 부작용 / 대안’
- 연도별 제도변경 전·후 명칭

을 조합한다.

### 2-4. 국내 선행 스캔의 종료 기준

‘검색을 많이 했다’가 아니라 다음이 충족되면 1차 스캔을 닫는다.

- 주요 기관·절차·행사군을 빠뜨리지 않았는가
- 반복되는 질문과 논거가 더 이상 크게 늘지 않는가
- 서로 다른 입장·이유를 확인했는가. 직접 주장이 미확인인 경우에도 검색범위와 아래 §2-5의 근거 구분을 기록했는가
- 직접 관련 판례·헌재결정의 존재 여부를 확인했는가
- 이후 원자료 검증이 필요한 주장 목록이 만들어졌는가

---

### 2-5. 논제 그대로의 주장과 인접 논거를 구분한다

- 자료대장에서 **실제 직접 주장 / 인접한 주장의 논거 / 강의용으로 구성한 논증**을 나눈다. 행사 참가자의 발언, 기관의 공식 의견, 법원의 판단도 서로 구분한다.
- 논제 그대로의 주장을 찾지 못해도 인접 자료의 사실·법리·가치이유를 근거로 검토할 규범적 논증을 구성할 수 있다. 논증의 전제와 자료의 역할을 밝히며 발언자·기관·판결에 그 결론을 새로 귀속하지 않는다.
- `직접 주장 미확인`은 `그런 주장은 없다`는 결론이 아니다. 확인 채널·검색어·원문 범위를 기록하고 이후 표적조사할 질문을 남긴다. 교수자가 논제를 선정한 의도도 자료 없이 추정하지 않는다.
- 보호 목적, 더 무거운 제재의 정당화, 실제 예방효과를 구분한다. 보호 필요·합헌 판단을 더 무거운 제재의 효과 입증으로 바꾸지 않는다.

## 3. 2단계 — 직접적인 국외 자료를 보완한다

국내 자료를 본 뒤, **같은 질문을 직접 다루는 국외 자료**를 찾는다.

우선순위:

1. 공식 법령·법원·정부·공공기관 자료
2. 동일하거나 매우 가까운 정책·제도 비교
3. 논제의 직접 효과를 평가한 연구
4. 직접 비교가 없을 때만 인접한 간접 연구
5. 체계적 문헌고찰·메타분석

국외 자료는 국내 쟁점을 덮어쓰는 용도가 아니다. 다음 중 무엇을 보완하는지 적는다.

- 국내에 없는 비교제도
- 직접 효과
- 장기 결과
- 권리·절차
- 실행조건
- 비용·자원
- 정책대안

대상·제도·결과가 다르면 **간접근거**로 표시한다.

---

## 4. 3단계 — 잠정 쟁점 5~7개를 도출한다

국내 선행 스캔과 직접 국외 자료를 함께 본 뒤 쟁점을 정리한다.

### 4-1. 쟁점의 조건

쟁점은 **자료유형이 아니라 판단이 갈리는 질문**이어야 한다.

좋은 쟁점:
- 법적 문턱을 충족하는가
- 피해자 지위와 사법개입은 병존 가능한가
- 특정 개입이 실제 결과를 개선하는가
- 보호 목적의 자유제한을 어디까지 허용할 것인가
- 외부 원인의 문제를 누구에게 개입해 해결할 것인가
- 대체체계가 실제로 작동할 수 있는가

나쁜 쟁점:
- 국내 통계
- 해외 사례
- 판례
- 토론회
- 지원센터
- 연구 결과

이런 항목은 **쟁점을 설명하는 자료**이지 쟁점 자체가 아니다.

### 4-2. 쟁점 통합 규칙

- 같은 질문의 세부 운영문제는 하나의 상위 쟁점으로 묶는다.
- 한 자료에서만 잠깐 나온 주변논점은 독립 쟁점으로 승격하지 않는다.
- 반복해서 등장해도 논제 판단을 바꾸지 않는 내용은 배경자료로 둔다.
- 한 쟁점에서 서로 다른 입장이 존재하는지 확인한다.
- 실제 근거가 한쪽에만 강하면 억지로 양쪽 근거량을 맞추지 않는다.
- 쟁점은 질문형으로 쓰고, 입장은 그 질문에 대한 서로 다른 답으로 둔다.

### 4-3. 잠정 쟁점표

| 잠정 쟁점 | 입장 A | 입장 B / 반론 | 국내에서 나온 핵심 근거 | 국외 직접·간접 근거 | 아직 부족한 자료 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

## 5. 4단계 — 쟁점별 표적조사를 한다

쟁점을 도출한 뒤에는 **각 쟁점을 실제로 판단할 수 있도록 부족한 자료를 표적 조사**한다.

쟁점별로 다음을 확인한다.

- 정확한 법령·법리·판례
- 공식통계와 원표
- 실제 국내 적용사례
- 운영·서비스의 실제 내용
- 국내 연구·면접·실태조사
- 직접 효과연구
- 권리·부담·부작용
- 비용·자원·수용능력
- 대안의 실행가능성
- 국외 직접 비교·효과근거
- 근거 공백

이 단계에서 **WEEK_RESEARCH_COVERAGE_TEMPLATE의 12개 영역과 공식통계 5축을 완전히 닫는다.**

즉 12개 영역은 초기 쟁점 발견 전에 모두 같은 깊이로 파는 목록이 아니라,

> **1차 스캔에서 누락을 방지하고 → 잠정 쟁점 도출 뒤 → 2차 표적조사에서 최종 PASS를 만드는 하드게이트**

로 사용한다.

---

## 6. 5단계 — 잠정 쟁점을 최종 쟁점으로 확정한다

표적조사 뒤 각 쟁점을 다시 감사한다.

다음 중 하나면 합치거나 삭제한다.

- 다른 쟁점과 사실상 같은 질문
- 근거가 아니라 단순 배경설명
- 논제의 직접 선택과 무관
- 자료를 추가해도 독립 판단축이 되지 않음
- 인접 주제의 흥미로운 내용일 뿐 오늘 논제에 직접 필요하지 않음

최종적으로 **5~7개 안팎의 판단축**을 남긴다.

각 쟁점에는 최소한 다음이 있어야 한다.

1. 질문형 쟁점 제목
2. 입장 A의 명확한 주장
3. 입장 B 또는 실질적 반론
4. 각 입장의 근거
5. 직접근거와 간접근거의 구분
6. 자료가 답하지 못한 점
7. 학생이 최종 판단할 때 볼 조건

---

## 7. 6단계 — 목차와 쟁점을 분리해 강의 순서를 만든다

**목차 = 배우는 순서**  
**쟁점 = 최종 판단 질문**

둘을 섞지 않는다.

기본 강의 흐름은 다음과 같다.

1. 논제와 현행 기준선
2. 법·절차·제도
3. 규모·실태·실제 사례
4. 실제 운영·서비스
5. 필요하면 국내외 비교
6. 주요 쟁점별 입장·근거
7. 효과·권리·실행조건 검증
8. 종합·각자의 판단

실제 주차에서는 주제에 맞게 순서를 바꿀 수 있다.

쟁점 페이지는 기본적으로:

> **쟁점 질문 → 입장/주장 → 근거 → 반론 또는 다른 입장 → 실제 근거상태 → 판단**

의 관계가 보이게 한다.

---

## 8. 7단계 — PPT 제작 전 최종 하드게이트

페이지별 구성안 전에 다음을 모두 확인한다.

- 국내 공개논의·정책·사법자료 선행 스캔 완료
- 직접적인 국외 자료 확인
- 잠정 쟁점 5~7개 도출
- 쟁점별 표적조사 완료
- 12개 필수 자료영역 최종 PASS
- 공식통계 5축 점검
- 판례·헌재결정 맵 완료
- 자료→쟁점 사상표 완료
- 자료→목차 사상표 완료
- 논제 정합성 감사 PASS

그 뒤에만 페이지별 구성안과 실제 PPT 제작으로 넘어간다.

---

## 9. 이 순서를 쓰는 이유

이 프로토콜은 세 가지 실패를 막는다.

### ① 자료부터 많이 모았지만 무엇이 쟁점인지 늦게 드러나는 문제
공개논의·사법판단을 먼저 보면 **실제로 반복된 판단축**을 초기에 잡을 수 있다.

### ② 처음 정한 찬반 틀에 자료를 끼워 넣는 문제
쟁점은 자료를 본 뒤 도출하므로 **강사의 선입견이 목차를 선점하는 위험**을 줄인다.

### ③ 쟁점을 찾았지만 근거가 얕은 문제
잠정 쟁점 뒤에 표적조사를 한 번 더 하므로 **법·통계·효과·권리·실행조건을 쟁점별로 보강**할 수 있다.
