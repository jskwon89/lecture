# 자료조사·강의 PPT 제작 유의사항과 방법 — W9 작업 정리

작성: 2026-10-29
근거: W9 「아동·청소년 대상 성범죄 출소자의 주거지를 제한하여야 하는가?」 v1~v76 제작 중 사용자 수정 지시와 사용자 편집본 검토

## 0. 이 문서의 범위

- 이미 다른 규칙 문서에 있는 내용은 본문을 다시 쓰지 않고 **조항 번호만 가리킨다**(§1 표).
- 본문(§2~§6)은 W9 작업에서 **새로 정해졌거나, 기존 규칙에 없던 방법**만 적는다.
- 사용자의 현재 명시적 지시가 이 문서보다 우선한다.

## 2. 사용자와 일하는 방식

1. **질문에는 답만 한다.** 사용자가 덱을 보며 묻는 동안에는 파일을 고치지 않는다. 고칠 점은 번호를 붙여 등록해 두고, 사용자가 "수정해 줘"라고 할 때 한꺼번에 반영한다.
2. **목록은 둘로 나눈다.** 「수정 목록」(반영할 것)과 「결정할 것」(사용자가 골라야 할 것)을 섞지 않는다.
3. **사용자 편집본이 새 기준본이다.** 사용자가 고친 파일을 받으면 그 파일 위에서만 고친다. 장 순서와 사용자가 쓴 문구는 지적한 곳 말고는 바꾸지 않는다. 전달할 때 바뀐 장 번호와 바뀐 이유를 함께 적는다.
4. **사용자 편집본을 검토할 때 볼 것.** 순서를 옮긴 뒤 생기는 오류가 많다.
   - `다음 →` 단서가 실제 다음 장과 맞는지
   - 본문 안의 「(○○쪽)」 참조가 옮긴 뒤의 쪽 번호와 맞는지
   - 목차 쪽·단원 간지의 항목이 실제 장과 맞는지(옮기거나 지운 장이 남아 있지 않은지)
   - 맨 뒤로 옮긴 장의 단원 표시(예: 「4-2 해외」 → 「보충자료」)
   - 칸을 넘는 글, 끝 마침표·물음표
   - 메모식 표기: 한글 자모 「ㅡ」, 「<->」, 「/」 같은 기호는 문장으로 바꾼다. 예: 「<-> 한국의 의무교육」 → 「한국은 홈스쿨을 의무교육 취학으로 인정하지 않는다.」
   - 사용자가 새로 쓴 사실 문장이 원자료 범위와 맞는지(예: 「12세 미만 아동 대상 성범죄자 전체」 → 실제 대상은 12세 미만 아동을 추행한 사람)
5. **화면 내용을 대본으로 옮기자는 제안을 하지 않는다.** 칸이 모자라면 문구를 줄이거나 장을 나누거나 띠를 없애는 안을 낸다. "대본에서 설명"은 해결책이 아니다.
6. **답변에서도 자료에 없는 연결을 만들지 않는다.** 예: 영상을 15쪽에 두면서 "주민 반대가 정부안의 배경"이라고 설명했으나, 정부안 제안이유는 "출소할 때마다 거주지를 둘러싼 논란이 반복되고 국민들의 불안이 커진다"까지만 말했다. 배치 이유도 자료 문장으로 댄다.
7. **산출물.** 전체 PPTX와 PDF를 함께 낸다. 파일명은 ASCII와 버전 번호(`W9_merged_v76.pptx`). 몇 쪽만 잘라 내는 파일은 사용자가 요청할 때만 만든다(예: 중간평가 두 장).

## 3. 자료조사

1. **조사 설계를 화면에 올릴 수 있게 원보고서에서 찾는다.** 설문·조사 결과를 쓰면 대상(누가 몇 명), 척도(예: 5점, 7점), 문항, 시기, 방식을 원보고서 본문·표에서 확인한다. "왜 그렇게 답했는가"를 물으면 같은 보고서의 면접·자유응답 쪽을 찾는다.
   - 예: KICJ 2021 전자감독 평가연구 [표 6-3](p.307, 직원 200명, 5점 척도, 2021.9.9~10.24 온라인)과 주거지 제한이 효과가 낮다고 본 이유(p.304: 직장·일용직·친척·병원 때문에 시군구를 벗어나야 함).
2. **평가 대상과 시점을 맞춘다.** 어느 자료가 어느 안을 평가했는지 확인한다. 2023년 500m 원안을 평가한 자료를 2024년 시설 지정안이나 22대 법안의 평가처럼 쓰지 않는다. 새 법안을 평가한 자료가 없으면 그 상태를 그대로 적는다.
3. **법안 쟁점은 전문위원 검토보고서에서 먼저 찾는다.** 검토보고서에는 제안이유, 현행 제도, 해외 입법례, 쟁점, 조문별 검토, 관계기관(법무부·법원행정처·소관 부처) 의견이 함께 있다. 앞선 법안과 같은 내용은 반복하지 않고, 새 법안에서 **추가로 나온 점**만 쓴다.
4. **판결은 심급 흐름과 당사자를 함께 확인한다.**
   - 1심 → 항소심 → 상고심의 판단과 이유를 각각 확인한다. 상급심만 보고 1심을 빼지 않는다(예: Doe v. Miller 1심 2004 S.D. Iowa는 소급처벌·자기부죄·실체적 적법절차를 들어 위헌, 제8연방항소법원이 뒤집음).
   - 원고·피고가 누구인지, `v.`(versus) 같은 표기, 심리 거부(certiorari 기각)의 뜻을 화면에서 푼다.
   - "다수의견이 무엇을 판단했는가"는 판결문 문장을 확인한다. 예: Miller 다수의견은 2,000피트라는 거리를 입법자가 정한 것으로 보았다.
5. **해외 제도는 근거 법조문과 적용 대상을 끝까지 확인한다.** 이름이 같은 법도 주마다 내용이 다르다.
   - 예: 플로리다 제시카 런스퍼드법(12세 미만 아동 추행에 최저 25년·평생 전자감독)과 캘리포니아 주민발의 83호(등록 의무가 있는 성범죄자 전체의 학교·공원 2,000피트 거주 금지)는 대상이 다르다.
   - 예: Ortiz v. Breslin의 1,000피트 제한은 뉴욕 Executive Law §259-c(14)(3등급, 학교 부지), 교정시설 안 주거형 치료시설은 Correction Law §73(10)이 근거다.
6. **연구는 비교군을 정확히 쓴다.** 전후 비교 연구에서 표본 전체를 "제한을 받은 집단"으로 쓰지 않는다. 처치·비교 집단이 무엇인지, 결과 지표(재유죄 여부, 걸린 시간)가 무엇인지 원문으로 확인한다.
7. **실제 사례 영상·보도.** 방송사·프로그램명·제목·방송일을 확인한다. 링크가 열리지 않아 내용을 모르면 짐작으로 자리를 정하지 말고 사용자에게 내용을 묻는다(W9: 첫 링크가 열리지 않아 위치를 잘못 정했다).
8. **평가 과제(논제)의 자료 균형을 확인한다.** 찬성·반대 각각의 공개 자료(법안 제안이유, 검토보고서, 관계기관 의견, 판례)가 있는지 확인하고, 한쪽이 부족하면 참고자료 안내를 제안한다.

## 4. 화면 문장

1. **모든 문장에 주어를 쓴다.** 축약된 표 칸에서도 "누가"가 빠지면 넣는다. 예: 「…2,000피트 안에 거주할 수 없다」 → 「이들 대상자는 …2,000피트 안에 거주할 수 없다」. 「12세 미만 …에 대해 강화했고」처럼 행위 주체(주 의회·법)가 무엇인지 문맥에서 바로 보이게 한다.
2. **두 문장 이상인 띠·하단 줄·칸이 줄바꿈되면 문장 경계에서 끊는다.** 문장 중간에서 줄이 넘어가지 않게 한다. 괄호로 시작하는 부분(예: 「(제8연방항소법원)」)은 앞 문장에 붙인다.
3. **중요한 내용을 먼저 쓰고, 법안·자료 이름은 괄호로 뒤에 둔다.** 예: 「출소 때마다 거주지 논란이 반복된다는 이유다(정부안 제안이유).」
4. **자료가 말하지 않은 결론을 쓰지 않는다.** 띠·하단 줄에서 자료 내용을 넘어선 판단("따라서 효과가 없다")을 덧붙이지 않는다.
5. **"이어서", "다음 쪽에서" 같은 진행 지시를 화면에 쓰지 않는다.** 장 사이 연결은 우상단 `다음 →` 단서가 맡는다.
6. **본문에서 다른 쪽을 가리킬 때는 쪽 번호를 쓰고, 순서를 바꾸면 다시 맞춘다.** 제작 스크립트에서는 제목으로 참조해 두고(예: `⟦보안처분의 개념⟧`) 합본할 때 실제 번호로 바꾼다.
7. **강조(하이라이트)는 그 쪽에서 전할 구절에만 쓴다.** 예: 판결 별지 준수사항에서 주거 관련 1항만 강조하고 나머지 항은 글자만 둔다.
8. **화면 크기를 키울 때는 줄 수가 늘지 않는 범위에서만 키운다**(W9: 글자 크기 종류별 +1pt, 줄 수가 늘거나 칸을 넘으면 원래 크기 유지).

## 5. 쟁점 쪽 구성 (W9에서 정한 형식)

1. **쟁점 정리 쪽**에는 이 강의의 질문만 둔다. 각 쟁점을 다루는 쪽 목록은 넣지 않는다.
2. **쟁점 한 쪽의 틀**
   - 열 머리는 쟁점마다 같다: 「찬성: 제한하여야 한다」 / 「반대: 제한하지 않아도 된다」.
   - 행은 주장 → 이유 → 근거 순서다.
3. **주장은 그 쟁점 질문에 바로 답하는 문장이다.** 질문이 "보호 이익이 부담보다 큰가"이면 주장은 「보호 이익이 주거 불안·감독 약화·지역 부담보다 크다.」 / 「주거 불안·감독 약화·지역 부담이 보호 이익보다 크다.」처럼 쓴다. 다른 질문에 답하는 문장(예: "거처와 지원을 함께 마련하면 된다")을 주장 칸에 두지 않는다.
4. **이유는 논증이다.** "~할 것이다", "~하면 ~해진다"처럼 주장을 받치는 논리를 쓴다. 이유 칸에 자료 인용("김재섭안 제안이유처럼")을 끌어오지 않는다.
5. **근거 칸에만 자료를 둔다.** 근거마다 어느 방식에 해당하는지 표시한다: `거리`(거리 제한) / `시설`(시설 지정) / `공통`. 자료가 어느 쪽 방식을 다뤘는지 사실과 맞게 붙인다.
6. **「자료의 한계」·「판단 기준」 줄은 쪽마다 의무로 두지 않는다.** W9 사용자 편집본에서 대부분 지웠다. 둔다면 짧게, 그 쟁점 판단에 실제로 필요한 것만 쓴다.

## 6. 덱 구성·제작 방법

1. **평가 안내 쪽은 쟁점 뒤, 보충자료 앞에 둔다**(W9 중간평가 두 장: 논제·제출 안내 / 평가 기준).
2. **영상 링크**
   - 관련 내용 줄의 오른쪽 끝에 「▶ 영상」만 쓴다. 긴 보도 제목은 화면에 쓰지 않는다.
   - 영상은 그 내용이 직접 이어지는 쪽에 둔다(W9: 창원 '가짜 주소' 보도 → 공개 주소와 실제 거주지 불일치 쪽, 조두순 피해자 가족 보도 → 거주 제한이 없는 현행법 쪽).
   - python-pptx로 장을 복제·합본하면 하이퍼링크 관계(rId)가 깨진다. 합본 뒤 링크를 다시 건다.
   - PDF에 링크가 살아 있는지 확인한다(`pypdf`로 `/Annots`의 `/URI`). 앱 미리보기에서는 링크가 안 눌릴 수 있으니 브라우저·Acrobat으로 열어 보라고 안내한다.
3. **사용자가 PowerPoint로 저장한 파일을 고칠 때**
   - PowerPoint는 글자를 단어마다 나눠 저장한다. 문자열을 바꾸기 전에 서식이 같은 조각을 합친다.
   - 원하는 위치에서 줄을 나눌 때는 문단 안에 줄바꿈(`a:br`)을 넣는다.
   - LibreOffice로 만든 PDF는 PowerPoint 내보내기보다 글자 폭이 넓어 줄이 더 넘어갈 수 있다. 최종 PDF는 PowerPoint 내보내기가 기준이며, 차이가 나는 쪽은 전달 때 알린다.
4. **전달 전 자동 점검**(순서를 바꿨거나 사용자 편집본을 받았을 때)
   - 각 장 `다음 →` 단서 ↔ 실제 다음 장 제목
   - 본문 「(○○쪽)」 ↔ 해당 쪽 제목
   - 목차·간지 항목 ↔ 실제 장
   - PDF 링크 수와 위치
   - 렌더 이미지로 칸 넘침·겹침 확인
5. **장 수를 늘리지 않고 칸을 맞추는 순서**: 문구 줄이기 → 상단 띠 없애기(사용자 허용 시) → 장 나누기. 글자 축소와 대본 이동은 쓰지 않는다.
