# 범죄·공공안전세미나Ⅱ — 주차별 강의·학생발표·토론문 표준구조 (개정 4판)

기준일: 2026-09-18 · 3판의 구조는 유지하면서 화면 단독 이해·구체적 설명 원칙을 보완한 공통 소스판 — 주차별 적용례는 각 주차 대화창에서 관리한다 · 체크리스트 항목 수는 내용 변경에 따라 달라질 수 있으므로 숫자로 고정하지 않는다

## 1. 목적

강사가 보여주는 사고의 구조, 학생이 구두로 발표하는 구조, 발표자료와 토론문(중간·기말)의 구조를 하나의 체계로 연결한다. **모든 주차가 공유하는 것은 동일한 사고의 문법이지 동일한 목차가 아니다.**

자료를 `개념 → 법조문 → 판례 → 통계 → 연구`처럼 고정 순서로 나열하지 않는다. 논제와 쟁점을 먼저 잡고, 각 자료가 어떤 물음에 답하는지에 따라 배치한 뒤 다시 판단으로 돌아온다.

강의자료는 자료를 소개하는 데서 끝나지 않는다. 각 자료가 **어느 쟁점에 답하는지**, 그 결과가 **서로 다른 입장에서 어떤 논거로 사용될 수 있는지**, 그리고 **자료만으로 정해지지 않는 판단이 무엇인지**를 종합 단계에서 분명히 회수한다. 강사는 특정 입장의 결론을 대신 내려주지 않는다.

## 2. 강사 강의자료의 8개 기능 블록

| 블록 | 역할 | 대표 내용 |
|---|---|---|
| ① 논제와 출발점 | 오늘 무엇을 판단할지 고정 | 정식 논제, 필요한 경우 짧은 사례·문제제기 |
| ② 범위와 핵심용어 | 논제가 묻는 범위와 의미 고정 | 공식 정의, 법적 구분, 필요한 측정기준 |
| ③ 현행 법·제도의 기준선 | 무엇을 바꾸려는지 이해 | 핵심 조문, 절차, 현행 제도 |
| ④ 핵심 쟁점 지도 | 뒤 자료가 답할 질문을 먼저 제시 | 판단이 달라질 수 있는 핵심 물음 |
| ⑤ 정책대안·비교기준 | 단순한 입장 선택을 넘어 선택지를 구체화 | 현행 유지, 부분 변경, 대체수단, 설계대안 |
| ⑥ 쟁점별 자료 검토 | 각 쟁점에 필요한 사실과 이유 확인 | 법령·판례·통계·연구·국제자료·사례를 쟁점별로 배치 |
| ⑦ 각 논거·대안이 놓칠 수 있는 점과 부담 | 한계·부작용·다른 수단 확인 | 연구 한계, 적용범위, 예상 부작용, 대안의 부담 |
| ⑧ 종합과 남는 판단 | 자료를 다시 논제로 회수 | 확인된 사실, 판단기준, 남는 불확실성, 결론을 좌우하는 전제 |

③~⑦은 필요에 따라 순서를 바꿀 수 있다. **핵심 쟁점 지도(④)와 「공통으로 인정하는 지점」은 종합 단계에 둔다.** 자료를 다 살핀 뒤에야 무엇을 두고 판단이 달라지는지, 무엇은 다투지 않는지가 확인된다. 2주차와 3주차가 이 배치로 확정되었다. 도입부에는 논제·범위·핵심용어와 자료를 읽는 순서(목차)만 둔다. 쟁점 지도를 도입부에 두는 주차는 예외이며 감사기록에 이유를 적고, 이때만 도입 지도와 회수 장의 문안을 한 쌍으로 관리한다.

**종합 단계의 표준 순서** — ⑤·⑦·⑧ 블록은 종합 단계에서 다음 순서를 기본으로 한다: 정책대안의 적용 범위 → 대안별 근거·실행 조건 → 효과의 불확실성을 다루는 방법 → 쟁점 지도(공통으로 인정하는 지점 + 물음) → 학생의 자기 논증 틀(결론·핵심 근거·남은 질문·판단을 바꿀 조건) → 마무리(이번 주 할 일·다음 주).

강사 자료에는 `주장` 블록을 두지 않는다. 강사는 결론을 제시하는 대신 자료가 어디까지 답했고 어떤 판단이 남는지 정리한다.

쟁점 수는 의무가 아니라 범위의 기준이다. 강사 자료는 보통 3~6개, 학생 발표는 결론을 좌우하는 2~4개로 압축한다.

## 3. 자료별 기능표

이 표는 **강사 제작용**이다. 학생에게 별도의 목록으로 외우게 하지 않는다.

| 자료 | 기본적으로 답하는 물음 | 주의 |
|---|---|---|
| 개념·정의 | 지금 어떤 대상을 말하는가 | 정의 자체가 결론이 되지 않게 함 |
| 법령·제도 | 현재 법과 절차는 어떠한가 | 현행 설명과 정책적 정당화를 구분 |
| 판례·헌재 결정 | 어떤 기준과 논거로 판단했는가 | 결론만이 아니라 쟁점과 연결 |
| 공식통계·실태자료 | 규모·추세·분포가 어떠한가 | 단위·분모·기간·분류기준 확인 |
| 학술연구 | 효과·관계·결과가 관찰되는가 | 말할 수 있는 범위와 한계 병기 |
| 해외제도·국제자료 | 다른 설계는 무엇인가 | 한국에 자동 적용하지 않음 |
| 기관 의견·여론조사 | 어떤 정책선택·가치판단이 제시되는가 | 사실 증명이 아니라 입장·인식 자료 |
| 보도·사례 | 쟁점을 어떻게 구체적으로 보여주는가 | 원자료를 대신하지 않고 사례를 빈도로 일반화하지 않음 |

## 4. 학생 지정토론의 구두 진행 구조

1. 논제와 자신의 결론
2. 논제의 범위와 핵심용어
3. 핵심 쟁점 — 강사 자료의 쟁점 지도는 종합 단계에 있으므로 발표자는 그것을 기다리지 않고 자기 결론을 좌우하는 2~4개 쟁점을 스스로 고른다. 강사 지도와 일치할 필요는 없다.
4. 쟁점별 근거: 자료와 이유 → 자료가 보여주는 것 → 결론과 이어지는 전제
5. 내 주장에 제기될 수 있는 주요 반대 논거 또는 다른 대안
6. 인정할 부분과 그에 대한 답변
7. 최종 판단: 처음 결론을 유지하는지, 조건을 붙이는지, 무엇이 아직 불확실한지

이 일곱 단계는 구두 발표 흐름이다. A4 발표자료를 일곱 칸으로 늘리지 않는다.

## 5. 발표자료 A4 1장

1. 입장과 핵심 주장
2. 근거와 출처
3. **내 주장에 제기될 수 있는 반대 논거와 그에 대한 답**
4. 자료의 신뢰성과 적용범위 점검

## 6. 토론문 (중간·기말 공통)

중간 토론문과 기말 토론문은 같은 논증 구조를 사용한다. 차이는 구조가 아니라 논제의 출처다 — 중간 토론문은 수업에서 다루지 않은 별도 논제를 강사가 제시하고, 기말 토론문은 4주차 이후 쟁점토론 논제 가운데 학생이 선택한다(본인 발표 논제 선택 가능).

- 서론: 논제의 범위, 필요한 핵심용어, 자신의 주장
- 본론: 서로 다른 입장의 논거를 포함한 핵심 쟁점별 판단, 근거자료, 자료의 의미, 전제와 한계
- 반론과 답변: 가장 강한 반대 논거 또는 대안, 인정할 부분, 자신의 답변
- 결론: 최종 판단, 핵심 전제, 남는 불확실성 또는 추가 확인할 점

## 7. 수업 유형별 적용

| 수업 유형 | 적용 |
|---|---|
| 1주차 오리엔테이션 | 공통 제작모형의 예외. 운영·평가·기본 도구 안내를 중심으로 별도 OT 분량을 적용한다. |
| 2~3주차 워밍업 | 학생 질문이 없어도 대본만으로 운영할 수 있도록 8개 기능을 거의 완전형으로 보여준다. 시간 배분은 강사가 정하며 대본 머리말에 정보로 기록한다. |
| 4주차 이후 지정토론 | 자료 자체는 발표가 없어도 강사 진행으로 수업 전체를 운영할 수 있는 분량으로 준비한다. 실제 수업에서는 학생 발표·질의가 전반부를 수행하고, 강사 정리 구간에서 빠진 쟁점·추가자료·대안·한계·종합을 보완한다. |
| 토론문(중간·기말) | 발표의 논증 골격을 글로 확장하며 자료 수보다 쟁점-근거 연결, 전제, 반론에 대한 답변을 중심으로 평가한다. |

## 8. 제작 체크리스트

### 구조
- 도입부에 논제·범위·핵심용어와 목차가 있고, 쟁점 지도가 종합 단계에 있는가?
- 각 자료가 어느 쟁점에 답하는지 한 문장으로 설명할 수 있는가?
- 자료 유형별 모음처럼 나열하지 않았는가?
- 대안이 중요한 논제라면 선택지가 판단 전에 보이는가?
- 종합 단계에서 쟁점 지도를 제시하고 그다음 장에서 학생이 자기 결론을 정리하는가?

### 자료와 표현
- 연구의 결과와 한계·적용범위를 함께 제시했는가?
- 사례와 빈도·효과 자료의 역할을 구분했는가?
- 확인할 사실과 판단할 물음을 한 칸에 섞지 않았는가?
- 화면만 읽어도 그 장의 핵심 사실·제도 또는 연구의 실제 내용·작동방식·결과·논제와의 관계를 기본적으로 이해할 수 있는가? 대본은 화면을 반복하지 않고 사례·맥락·추가 설명을 보완하는가?
- 강사 자료와 학생 발표·토론문의 요구가 같은 사고 구조로 이어지는가?
- `가능하다·연계된다·지원한다·관리한다·대응한다·조치한다` 같은 추상어 뒤에 실제 주체·행위·조건·절차 또는 조치가 적혀 있는가?
- 연구자료는 `무엇을 비교했나 → 어떤 결과가 나왔나 → 그 결과가 어느 쟁점과 연결되나`가 보이는가?
- `다르게 본다·살펴볼 필요가 있다·예정된 조치`처럼 결론을 흐리는 표현 대신 확인된 사실·조치·결과를 직접 적었는가?

### 제작·납품 (제작 지침 5판 §7)
- 채움을 제거한 장의 글자색을 다시 확인했는가?
- 새로 생성한 덱에서 이전 버전의 도해 요소(화살표·색 면·막대·도식)가 대응 요소로 존재하는가?
- 장을 삽입한 뒤 대본 머리말·배분표·장별 지정의 번호를 재매김했는가?
- 각 노트 슬라이드가 자기 슬라이드를 역참조하는가?
- 화면을 대본 없이 읽었을 때 배경·핵심·결과·한계·논제 관계가 확인되는가?


## 9. 개정 이력

- **4판(2026-09-18)** — 3판의 8기능 구조와 쟁점 지도 배치는 유지. `화면은 speaking cue 수준` 문구를 삭제하고, 화면 단독 이해·구체적 작동 설명·결론형 문장·쟁점 연결 기준을 체크리스트에 반영.
