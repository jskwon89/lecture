# Source rules archive

이 폴더는 Git Canonical을 만들 때 사용한 기존 프로젝트 소스 원문을 보존한다.

## 현행 적용

- 실제 PPT 제작 시 **먼저 `../PPT_RULES.md`를 따른다.**
- 이 폴더의 파일은 누락·충돌 감사와 과거 결정의 근거 확인용이다.
- 원문 소스가 Canonical과 충돌하면 조용히 섞지 않는다. `../RULE_SOURCE_MAP.md`에 기록된 supersede 관계를 따른다.

## 중요 supersede

`guideline_v11_1_20260918.md`의 **“명확한 주체가 있으면 제목 맨 앞에 반드시 둔다”**는 규칙은 현재 효력이 없다.

현행 제목 규칙은 `../PPT_RULES.md §6-4`이다.

- 제목은 장의 핵심만 남긴 간결한 표제형을 우선한다.
- 문맥상 자명한 대상·조건은 반복하지 않는다.
- 주체가 없으면 모호할 때만 실제 행위의 주체를 쓴다.
- 연구자가 만든 실험조건을 제도 자체가 수행한 것처럼 쓰지 않는다.
