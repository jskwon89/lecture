# 8주차 현재 상태 — AI CCTV

갱신: 2026-10-08 · 검토용 초안 v1

**현재 자료:** [week8_ai_cctv_20261008](week8_ai_cctv_20261008/README.md)

**논제:** 범죄 용의자를 식별·체포하기 위해 공공 CCTV 영상을 AI로 실시간 분석하는 것을 허용하여야 하는가?

기존 조사 56항목·역사/사례 보완 22항목·추가 법령 2항목을 통합했다. 수령본과 원본 ZIP은 바이트 그대로 보존했다. 본편 44장과 보충 9장의 실제 PPT, 목차, 페이지 구성안, 낭독 대본과 목차·대본 DOCX를 작성했다.

내용 53장·PPT 렌더 53장·DOCX 20쪽의 페이지별 검수를 완료했다. 각각 PASS 53/53/20, HOLD 0, 미검토 0이다. 검수 근거와 전달본 해시는 [QA_REPORT.md](week8_ai_cctv_20261008/qa/QA_REPORT.md)에 연결했다. 내용 판단은 화면·대본 수동 독해이며 자동 도구는 기록·패키지 일치만 확인한다.

## 이어 할 작업

1. 현행 master의 `AGENTS.md`, current 진입점과 콘텐츠·PPT·작업 규칙을 다시 확인한다.
2. [목차](week8_ai_cctv_20261008/W8_outline.md)와 실제 PPT p.1부터 사용자와 검토한다.
3. 보충 9장의 선택 여부와 95분 운영안을 실제 리허설로 조정한다.
4. 수정 페이지는 화면 이해·대본·앞뒤 연결·렌더를 다시 검수하고 원본 JSON, 출력물, 검수 기록, 해시를 함께 갱신한다.

## 유지할 구분과 한계

- 실시간 얼굴 대조, 실종자 외형 검색, 사후 얼굴 검색의 자료 역할을 유지한다.
- 실제 기관의 입장·판결과 강의용 논거·설계안을 구별한다. 국내외 법령의 적용 범위를 유지한다.
- 국내 실시간 1:N 수사의 연결 원표·직접 인과효과, D17 고시 전문은 미확인이다. 숫자 0이나 확인된 효과로 채우지 않는다.
- 현재 자료는 사용자 확정 전 초안이다. `finals/`로 옮기거나 기존 다른 주차의 기준본을 바꾸지 않았다.
