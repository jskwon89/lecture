## Git 반영 검증 방법

최신 master 재확인 → 기존 tree 기반으로 변경 파일만 반영 → 원격 파일을 해당 커밋으로 다시 받아 SHA-256 manifest를 대조 → 강제 갱신 없이 master 반영. 원격 검증 실행 결과는 반영 후 보고한다. 이 문서의 PASS는 위 로컬 검증 범위를 뜻한다.
