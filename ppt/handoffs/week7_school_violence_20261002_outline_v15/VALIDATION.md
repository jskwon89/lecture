# v15 검증 범위

- 기존 v14 29개 페이지를 모두 한 개 주 배치 단원으로 연결했다. 새 실제 PPT 페이지 번호는 부여하지 않았다.
- 7개 학습 단원과 6개 잠정 쟁점을 구분했다. 도입·단원별 새 내용·이미 배운 내용·다음 질문·자료·종합 회수를 기록했다.
- 도입 가상 비교 1회와 p.1~13의 기존 문구·대본 보존을 적용했다. 반복 정의 대신 새 자료의 역할을 명시했다.
- 판결의 실제 판단·공개논의의 실제 제안·강의용 찬반 논증을 구분했다. J01의 민사판단, S06의 법 적용범위, S12의 당시 해외 성인·학교 주변 제도를 한국 교내 형사 가중 판시로 바꾸지 않았다.
- 공식통계 5축·12개 검토영역의 확보 출발자료와 남은 확인을 기록했다. 미조사 항목을 검색 완료로 표시하지 않았다. 효과·비용·2026 원표·현행 개정 대조가 남아 있다.
- 사용자 최종 승인·연구 게이트 PASS·전체 강의 완료·새 PPT 제작 완료로 표시하지 않았다.
- 편집용 JSON의 단원·쟁점·29개 페이지 대응과 파일 해시를 로컬 확인한다. 원격 반영 뒤 같은 커밋에서 파일을 다시 내려받고 `sha256sum -c`로 대조한다.
- DOCX는 별도 렌더·전체 페이지 시각 검수 후 제공한다. 해당 검수 결과는 최종 보고에 표시하며 실제 PPT의 렌더 검수와 혼동하지 않는다.

## 실행한 확인

- 편집용 JSON: 단원 7개·쟁점 6개·v14 29개 페이지의 중복 없는 주 배치·100분 잠정 안배 확인. 마지막은 찬반 주장과 근거이며 학생 결론 작성 단계가 없다.
- 각 쟁점의 찬성·반대 주장에 앞의 자료와 연결 이유를 모두 기록했다.
- DOCX 11쪽을 렌더하고 모든 페이지를 원래 해상도로 시각 검수했다. 빈 페이지·내용 넘침·표 겹침을 수정했고 마지막 변경은 2쪽 질문 ID 열 폭으로, 나머지 10쪽 렌더 바이트가 동일함을 확인했다.
- 실제 PPTX나 전체 자료조사 게이트의 검수 완료를 뜻하지 않는다.
