# 규칙 변경 검증

- 요청 범위: 화면에서 대본 내용을 그대로 볼 수 있어야 하고 같은 말을 쓴다는 기준의 하드게이트화, 방어문 금지의 제안 단계 적용, 실행 도구.
- CONTENT §4-2-2를 단일 상세 기준으로 두고 Canonical §6-6-1·SCREEN_FIRST_REVIEW·WORKFLOW·AGENTS·README·current에서 연결했다.
- 충돌 해소: Canonical §6-6-1 “대본은 화면 문구를 다시 읽는 용도가 아니다”와 ‘오해 방지’ 대본 역할을 대체하고 대체표·SOURCE_MAP §31에 기록했다. 화면 단독 이해·SCRIPT-HIDDEN TEST·§4-2·§4-2-1은 유지된다.
- 도구 실행 확인: `check_script_screen.py`를 W8 v16 검토본(65장)에 실행해 문단별 비율·위치 지시·방어문 후보 보고가 생성됨을 확인했다. 탐지 후보 중 법조문 제외 조항·판결 내용·당사자 논거는 사람이 유지 판정했다. 도구는 의미 PASS를 인증하지 않는다.
- W8 v16 PPTX는 사용자 확정 전 검토본이라 이번 커밋에 넣지 않았다.
- MANIFEST는 자신을 제외한 이번 변경 파일의 UTF-8 바이트 SHA-256을 포함한다.
