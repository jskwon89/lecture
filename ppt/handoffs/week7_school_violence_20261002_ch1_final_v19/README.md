# W7 도입과 1장 내용 최종 정리본 v19

사용자의 “1장 최종정리” 요청에 따라 v16 전체 초안에 v17 채택된 맥락 수정과 v18 법조문 삽입을 통합했다. 도입 4개와 1장 7개 내용 화면의 문구·낭독 대본·출처·상세자료·제작 메모가 현재 기준이다.

새 번호는 실제 PPT 번호가 아니라 내용 작성 번호다. v16 p12의 형벌·학생 조치 기준은 두 화면으로 나눴다. p6 공동생활은 3장, p13 선행 조치 경로는 4장, p8 김현주 교사 사례는 5장에서 처음 설명한다. 세 내용의 원안은 JSON relocations에 보존했다. p14는 독립 화면을 없애고 마지막 대본에 흡수했다.

이번 완료는 도입·1장의 내용과 대본 정리다. 실제 PPTX 반영·전체 강의 작성·연구 게이트 완료와 구분한다. v15 전체 단원 순서와 마지막 쟁점별 찬반 주장·근거 정리의 역할을 유지한다. 다음 내용 작성은 2장의 실태 원표와 학교생활 피해다.
