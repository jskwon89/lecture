# v19 검증 기록

## 내용과 흐름

- 도입4+1장7. 순서는 v16 대응 1→2→3→4→5→7→9→10→12 형벌→12 가해학생 조치→11이다.
- 정식 논제를 3번 화면에 제시한다. 교실·공원 가상 비교는 이 화면에서 한 번만 사용하고, 두 경우 모두 수업 종료 이후의 사적 만남으로 맞췄다.
- 학생·비학생의 네 조합, 법정 행위·피해 요건, 학생인 피해자와 가해학생 조치의 대상을 화면에서 확인할 수 있다.
- 제재별 결정 주체·목적·예시, 형사책임의 행위 당시 연령, 보호절차의 소년 해당 여부를 유지했다.
- 학교폭력예방법 제2·17조, 시행령 제19조, 형법 제9·51조 원문과 시행일을 국가법령정보센터에서 재대조했다. 원문과 쉬운 설명, 생략과 전문을 구분했다.
- 형법 4개 항목과 시행령 5개 항목을 각각 제시한다. 협박·보복 요청 사유, 대상 조치 제6~9호, 의무교육 퇴학 예외를 화면·대본에 유지했다.
- 원안 p6→3장, p13→4장, p8→5장 이동을 통합했으며 1장에서 이미 설명한 것처럼 후속 작성하지 않는다. 원문·출처를 JSON relocations에 보존했다.
- p14 전환은 현재11 대본 마지막에 흡수했다. NEXT·단원·번호·출처 역참조를 재배열과 함께 갱신했다.
- 낭독용 대본·출처·강사용 상세자료·내부 제작 메모 네 구역이 모든 현재 내용 화면에 있다. 가상 예시의 실제 사례화, 보도의 처벌 비교, 판결에 직접 차등 주장을 귀속하는 문구가 없다.
- 실제 화면 문구만 읽는 점검, 제목·앞뒤 흐름·중복 점검을 완료했다. 학생용 상세 URL 각주는 없고 출처는 노트와 자료대장에 보존했다.

## 문서 QA

- 파일 W7_도입과1장_최종정리_v19.docx, SHA-256 `35fcf0d5fb5030352ac60dd09ec7d99958df5a018da648b3441811a030fa8601`.
- Letter 세로, 본문 11pt Pretendard v1.3.9. 표는 가변 행 높이와 회색 경계선, 열별 폭·여백·정렬을 사용했다.
- LibreOffice와 패키지 render_docx.py로 17쪽 렌더. 도입·1장 내용은 한 화면 문구와 대본을 문서 한 쪽에 배치했다. 상세자료는 별도 뒤 구역에 배치했다.
- 전 17쪽의 원본 크기 이미지를 시각 점검했다. 마지막 문구 수정 후 변경된 6·12쪽은 다시 확인했고 다른 쪽은 이전 점검 이미지와 SHA-256 동일성을 확인했다.
- 한글 누락·잘림·겹침·표 이탈·고립 문단·빈 끝 페이지가 없는 최종 렌더를 확인했다. 초기 임시 프로필의 폰트 탐색 문제를 해결하고 정상 렌더만 검증본으로 사용했다.
- 자료의 조건과 법문 항목, 네 가지 학생 조합, 이동 목록, 모든 출처 ID·NEXT·노트 구역의 구조 검사를 통과했다.

## 전달과 남은 범위

- 실제 PPTX·v14~v18 원본·공통 규칙·디자인 도구는 변경하지 않았다. 이번 통합본이 내용 작성의 현재 기준이다.
- DOCX는 별도 전달하며 Git에는 텍스트 기준본과 확인 기록만 반영한다. 렌더 이미지·PDF·폰트·임시 파일은 올리지 않는다.
- 소년법 전문·세부 고시·2026 가이드북 대조와 2~7장 작성·실제 PPT 제작은 별도 진행한다. 이 문서는 전체 연구 게이트 PASS를 표시하지 않는다.
- 로컬 MANIFEST 전체 검증을 통과했다. 커밋 뒤 원격의 모든 변경 파일을 읽어 로컬 바이트와 대조한다.
