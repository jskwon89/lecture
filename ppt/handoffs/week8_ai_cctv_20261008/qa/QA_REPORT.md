PPT의 화면만 먼저 읽어 대상·행위·조건·결과·질문의 답을 확인하고 대본·근거 범위·앞뒤 연결을 재독했다. 실제 화면 문구와 대본 문구, 점검 초점과 재독 결과를 53장에 기록했다. 설명이 원자료의 범위를 벗어나는지, 실제 기관 의견과 강의용 논거가 구별되는지도 확인했다. 자동 도구는 기록·구조의 일치만 검사한다.

## 수정과 재검수

- 첫 렌더에서 긴 문장의 Office 한글·영문 혼합 간격을 반영해 줄바꿈 여유를 보정했다. 표 13개의 기본 테두리는 회색 실선으로 명시했다.
- p.16의 불필요한 연령 세부를 삭제했다. 최종 렌더와 직전 전체 검수본의 52개 PNG가 바이트 동일하고 변경된 16쪽을 다시 열어 확인했다. 노트 출처는 재확인 URL을 우선 사용한다.
- DOCX 제목 스타일에서 남아 있던 파란색 기본 테두리를 제거하고 전 20쪽을 다시 읽었다.
- C형 행은 23장·70행. 본문 위·아래 잉크 여백 차 최대 0.0392인치, 라벨 세로 중심 오차 최대 0.0117인치, 라벨 좌우 여백 차 최대 0.0233인치로 각각 기준 0.05인치 이내다. 마지막 구분선은 53장 모두 6.72±0.05인치다.

## 구조와 데이터

- 슬라이드 53, 발표자 노트 53, 편집 가능한 표 13, 네이티브 차트 1 및 내장 Excel 원자료. 차트 값 4.0·0.2를 XML과 내장 자료 구조로 확인했다.
- 모든 화면의 제목·행 문안, 모든 노트의 낭독 대본이 내용 JSON과 일치한다. 학생 화면에 상세 URL 없음. 노트 네 영역과 출처 ID를 확인했다.
- 자료 80항목의 ID와 사용 관계가 일치한다. 45항목은 화면·대본·강사용 상세자료에 연결하고 35항목은 원자료로 보존했다. 중복 URL 자료의 이력과 성격은 유지한다.
- 패키지·배치 구조 검사: 오류 0. 배치 검사기의 표 하단 경고 5건(p.37·39·40·41·42)은 추정 초과량 0인치이며 실제 렌더에서 하단 선·셀의 겹침이 없음을 확인했다.
- Pretendard만 명시 인코딩되고 첫 당사자 도구 재가져오기는 성공했다. W2 실제 참조본의 일부 상속 폰트를 자동 해석하지 못하는 검사기 제한 때문에 자동 폰트 정책은 Git Canonical의 명시 디자인 값(Pretendard)을 사용했다. W2 원본의 실제 인코딩과 렌더를 별도로 확인했다.
- Office 본체 실행 시험은 하지 않았다. LibreOffice 렌더·패키지 검사·Artifact Tool 재가져오기가 확인 범위다.
