## 점검 재실행

이 폴더에서 다음 명령을 실행한다.

```bash
python tools/check_content_review.py AI_CCTV_역사사례_페이지내용.json AI_CCTV_역사사례_검수기록.json
```

이는 파일·인용·페이지 대응 검사다. 사실의 정확성과 화면 이해 가능성은 검수기록의 수동 검토 대상이다.
검수용 PDF와 페이지 이미지는 배포 묶음에 포함하지 않았다. 최종 DOCX와 페이지 이미지의 해시는 검수기록에 있다.
