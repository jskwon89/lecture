# v17 검증 기록

- v16의 내용번호 1~14를 빠짐없이 대조했고 각 화면 문구·대본과 v15 단원 역할을 검토했다.
- 번호별 처리, 이유, 구체적 보완, 상태, 출처를 기록했다. 확정 이동 2건과 추가 권고를 구분했다.
- 사용자 동의 배치: p8 김현주 교사 사례→5장, p13 심의 전 접촉금지·긴급조치→4장. p8을 1·2장에서 처음 소개한다는 구안의 가정은 후속 작성에서 쓰지 않는다.
- 권고 순서의 도입4·1장6개 내용번호와 이동3개·전환흡수1개의 합집합은 원래 14개 번호를 모두 포함하며 중복이 없다. 다만 이 권고 전체를 사용자 확정으로 표시하지 않는다.
- 사용한 13개 출처 ID는 모두 v16 자료대장에 존재한다. 기존 확인 범위·추가 법령 대조 과제를 유지한다.
- 새 통계·효과연구·법령 원문 확인을 완료한 것으로 표시하지 않는다. 실제 PPT·DOCX·렌더 검수를 이번 기록의 완료 범위로 표시하지 않는다.
- v15·v16 원본과 공통 규칙·디자인·실제 PPTX는 커밋 대상에서 제외한다.
- 파일별 SHA256은 UTF-8 원문으로 산출한다. 실행 환경이 연결되지 않아 셸의 sha256sum 명령은 실행하지 않았으며, 표준 빈 문자열·abc 검증값을 통과한 JavaScript SHA256 계산으로 작성하고 원격 조회 원문에 재계산해 대조한다.
