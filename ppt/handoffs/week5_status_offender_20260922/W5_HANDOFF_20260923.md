## 3. 논제와 8개 단원의 역할

**논제: “성매매가 우려되는 가출 청소년을 우범소년으로 송치하여야 하는가?”**

논제는 단순히 “피해자인가, 우범소년인가”라는 이름 선택에 그치지 않는다. 이 청소년에게 어떤 보호·지원이 필요한지, 그와 별개로 우범소년 송치 요건이 성립하는지, 이미 존재하는 피해지원·복지 경로와 비교하여 소년사법 경로를 유지·축소·대체·보완할 이유가 무엇인지를 묻는다.

| 단원 | 현재 제목 | 학생이 이해해야 할 질문 |
|---|---|---|
| 1 | 논제의 대상과 현행 우범소년 제도 | 누구를 어떤 요건·절차로 송치하는가? 피해 위험과 장래 범법 우려는 어떻게 다른가? |
| 2 | 성매매 피해청소년의 법적 지위 변화 | 왜 피해청소년을 다루는 법의 관점이 바뀌었고, 지금 어떤 경로가 마련되어 있는가? |
| 3 | 성착취 위험의 규모와 실제 맥락 | 위험은 어떤 환경에서 나타나며, 통계는 누구를 분모로 무엇을 보여 주는가? |
| 4 | 우범소년 제도의 실제 운용 | 실제 얼마나, 누구에 의해, 어떤 사건·처분으로 운용되는가? |
| 5 | 피해지원과 소년사법은 무엇을 다르게 제공하는가 | 두 경로의 서비스·치료·강제성·자유 제한·지속성은 어떻게 다른가? |
| 6 | 현장 판단의 어려움과 제도개선 논의 | 지원이 끊기거나 반복 피해가 발생하는 이유는 무엇이며, 제도를 어떻게 고칠 것인가? |
| 7 | 비교제도와 효과근거 | 다른 제도는 이 문제를 어떻게 다루며, 개입 효과에 관해 무엇을 알 수 있는가? |
| 8 | 주요 논거와 최종 판단 | 법 적용과 정책 판단을 나누어 어떤 근거로 결론을 내릴 것인가? |

고정해야 할 구분:

- 보호가 필요하다는 사실과 **우범소년 법정요건 충족**은 다르다.
- 성착취 **피해를 당할 위험**과 **이 청소년이 앞으로 범죄에 해당하는 행동을 할 우려**는 다르다.
- 경찰도 송치 단계에서 요건을 판단한다. 법원은 송치 사실만으로 결론을 내리지 않고 독립적으로 심리·판단한다. “판사만 판단한다”로 단순화하지 않는다.
- 현행법을 적용하는 판단과 제도 자체를 유지·축소·대체·보완하는 판단을 나눈다.
- 비교대안은 “송치 대 아무 조치도 하지 않음”이 아니다. 피해지원·복지 경로가 이미 있다.
- **가상사례를 새로 만들지 않는다.** 실제 사례의 빈칸을 추측으로 채우지 않는다.
- 강사는 특정 입장의 결론을 대신 정하지 않는다. 주장과 근거, 반론과 확인 질문이 자연스럽게 이어지도록 배치한다.

## 6. 근거별 확인 수준과 활용 위치

여기 적은 내용은 기존 확인 결과의 인계다. 새 법률 판단·최신 통계를 추가할 때에는 원문과 현행성을 다시 확인한다. 자세한 서지·페이지·URL은 최신 대본과 `content.json`에 있다.

### B 사례의 “왜 7호였는가”에 대해 현재 말할 수 있는 범위

담당 변호사 보고에는 **부모의 보호 곤란, 부모의 시설 수용 요청, 치료 필요성**이 처분과 관련된 사정으로 제시되어 있다. 이 내용은 송치 경위인 가출·부모 동의 없는 소액결제·성인 남성과의 접촉 및 “성범죄 연루 우려”와 구별해 설명한다.

그러나 구체적 진단, 처분 시설, 대체 치료 경로와의 비교, 법원의 상세한 선택 이유까지 확보한 것은 아니다. **“성매매 위험 때문에 7호를 받았다” 또는 “7호이므로 매우 중대한 비행이었다”라고 단정하지 않는다.** 7호의 법정 내용은 병원·요양소 또는 소년의료보호시설 위탁이며, 이를 정식 처분명인 것처럼 “치료감호”라고 부르지 않는다. 처분이 내려졌다는 사실 자체는 효과의 근거가 아니다.

2. **제7장 옛 제목**: “비교제도와 효과·권리·실행조건” 대신 현재 “비교제도와 효과근거”를 적용하고 자료 배분을 수정한다.

4. **국외 연구 E01 서지 혼동**: PMC8427984는 Wilson, Brennan & Olaghere(2018), *Police-initiated diversion for youth to prevent future delinquent behavior: a systematic review*, DOI 10.4073/csr.2018.5이다. *Formal system processing of juveniles: effects on delinquency*와 하나의 연구로 합치지 않는다. 정정 메모는 16쪽 수정안에 있고, 원래 자료대장 반영은 남아 있다.

## 9. 디자인·표현에서 되돌리지 말아야 할 결정

Canonical v1.6에서 사용자 승인으로 정합화한 값:

- 행 결론 **14pt Bold**, 보충 **12.5pt**. 과거 12.5/11.5pt로 되돌리지 않는다.
- **본문 내용 묶음을 행의 세로 가운데에 배치**한다. 텍스트박스 내부의 위쪽 정렬과 구별한다.
- **제목 오른쪽 칩을 쓰지 않는다.**
- Pretendard를 설치·확인한 뒤 줄바꿈과 렌더를 검수한다. 넘친다고 글자를 축소하지 않는다.

사용자 피드백의 핵심은 “강조를 줄이라”가 아니라 **정보관계와 핵심이 화면에서 분명히 보이도록 선택하라**는 것이다.

- 기능이 있는 진한 구조선, 표 시작·마감선, 비교 열 제목, 변수명, 요건 결합 기호, 절차 화살표는 보존한다.
- 같은 경계에 진한 세로 표지와 진한 가로선을 겹치지 않는다. 그렇다고 다른 역할의 선까지 모두 지우지 않는다.
- 상단·본문·하단을 모두 같은 강도로 진하게 만들지 않는다. 기능에 따라 강조의 우선순위를 정한다.
- 보조 구분선은 옅은 회색으로 낮춘다. 텍스트박스 기본 외곽선은 없다.
- 상자는 비교·그룹·범위 표시 등 역할이 있을 때 쓴다. “항상 상자” 또는 “항상 상자 없음”으로 고정하지 않는다.
- “성착취 피해 위험 / 소년법상 장래 범법 우려” 같은 **비교 대상의 명칭을 삭제하지 않는다.**
- 하단 밴드는 해당 페이지 전체를 정리하거나 구체적인 질문을 던진다. 앞 문장의 단순한 뒷부분이나 다음 장 예고를 넣지 않는다.
- 출처 검증은 계속하되 화면 하단 각주는 기본적으로 숨긴다. 출처·면수·한계는 노트와 대본에 남기고, 이해에 필요한 법조문 번호 등은 본문에 둔다.
- 법률 설명은 쉬운 말로 풀되 요건·주체·절차의 차이는 보존한다.
- 자료가 “무엇을 보여 주는가”를 먼저 설명한다. 모든 페이지를 자료 한계만 나열하는 화면으로 만들지 않는다.

## 11. 재생성·Git 저장 실무

제1장 패키지의 재생성 파일:

- `content.py` → `content.json`: 대본·출처 데이터. JSON만 고치면 다음 실행에서 덮어써질 수 있다.
- `build.mjs`: 실제 PPT 화면의 편집 가능한 객체 생성.
- `normalize.py`: 폰트·문단 간격 등 OOXML 정규화.
- `finalize.mjs`: 검증 및 최종 파일 생성.
- `build_docx.py`: 자료와 강의 대본 DOCX 생성.

화면 문구와 대본은 서로 다른 코드 부분에 있으므로 한쪽만 수정하지 않는다. 새 생성 파일·검증 결과는 새 버전 또는 새 경로에 쓰고, 기존 전달본을 덮어쓰지 않는다. 구체적인 실행 의존성과 순서는 패키지 README 및 코드에서 확인한다.

렌더에서는 Pretendard가 실제 적용됐는지 확인한다. PDF 변환기의 격리된 사용자 환경 때문에 설치한 폰트가 누락될 수 있으므로 폰트 대체가 보이면 설정을 해결한 뒤 다시 검수한다.

Git에 남길 것:

- 실제 PPTX·자료/대본, PDF·전체 접촉시트, 검색용 본문, 출처·검수 기록.
- 추가·수정·삭제 파일 목록과 `ppt/CHANGELOG.md`.
- 파일별 SHA-256 목록. 기존 `revision_20260923/MANIFEST.sha256`의 앞선 파일 항목을 버리지 않는다.
- 넘겨받은 파일은 바이트 그대로 저장하고 업로드 후 해시를 대조한다.
- 코드를 수정·커밋하면 해당 코드를 실행해 확인한다.
- 폰트 파일, 배포권 없는 원문, `__pycache__`, `*.pyc`, 렌더 중간 파일은 커밋하지 않는다.

과거 임시 작업 경로·첨부 이미지가 다음 대화에서 사라져도, **Git의 통합본·대본·검색용 본문·검수 기록이 우선 복구 지점**이다. 출처 PDF 자체가 Git에 모두 들어 있는 것은 아니므로 원문 링크를 사용한다.
