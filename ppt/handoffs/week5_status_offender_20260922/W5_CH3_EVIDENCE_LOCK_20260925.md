# 5주차 제3장 근거 잠금 — 가출·성착취 위험의 실제 연결

작성일: 2026-09-25 KST  
논제: **성매매가 우려되는 가출 청소년을 우범소년으로 송치하여야 하는가?**

## 1. 제3장 본편 구조 잠금

제3장은 **3장**으로 구성한다.

1. **피해 당시 가출 통계**
   - 2017~2023년 신상정보등록연도 기준 성매매범죄 피해자 2,943명
   - 피해 당시 가출 553명 = 18.8%
   - 성매수 101/1,674 = 6.0%
   - 성매매 강요 160/407 = 39.3%
   - 성매매 알선·영업 292/862 = 33.9%
   - 분모는 가출청소년 전체가 아니라 성매매범죄 피해자.

2. **온라인 피해 경로**
   - 성평등가족부·한국여성인권진흥원 「성착취 피해아동·청소년 지원센터 2025년 연차보고서」 공식 보도자료 기준.
   - 지원센터가 지원한 아동·청소년 1,226명 중:
     - 채팅앱 539명 = 44.0%
     - 사회관계망서비스(SNS) 474명 = 38.7%
     - 공식 자료가 두 범주를 합쳐 **온라인 매체를 통한 피해 82.7%**라고 명시.
   - 같은 자료의 피해유형(복수응답):
     - 조건만남 942건 = 37.9%
     - 폭행·갈취 289건 = 11.6%
     - 디지털 성범죄 280건 = 11.3%
     - 길들이기 206건 = 8.3%
   - 이 페이지는 ‘가출→성착취’ 인과를 주장하는 용도가 아니라 성착취 피해의 **접촉 경로와 피해유형**을 보여주는 맥락 자료로 사용한다.

3. **2024 거제 가출청소년 성매매 강요 사건**
   - 2024.7.24. 창원지검 통영지청이 이른바 ‘가출팸’ 구성원 3명을 구속기소했다고 보도됨.
   - 가출 중학생 피해자를 상대로 2024년 2~4월 경남 거제 일대에서 폭행·협박하고 26차례 성매매를 알선한 혐의.
   - **가출 상태의 숙식·생활 의존이 폭행·통제·성매매 강요와 결합되는 실제 맥락**을 보여주는 사례로만 사용한다.
   - 발생률이나 우범소년 송치 효과의 근거로 사용하지 않는다.
   - 현재 확인된 공개 근거층위는 검찰 발표를 인용한 언론보도. 검찰 원문 보도자료는 웹 검색에서 직접 확보하지 못함.

## 2. 제3장 슬라이드 역할

### 슬라이드 A — 피해 당시 가출 통계
**피해 당시 가출은 성매수보다 성매매 강요·알선 피해에서 훨씬 높은 비율로 나타났다.**

### 슬라이드 B — 온라인 피해 경로
**2025년 지원센터가 지원한 피해청소년의 82.7%는 채팅앱·SNS를 통한 피해로 분류됐다.**

화면 필수 범위:
- 지원센터 지원 아동·청소년 **N=1,226**
- 채팅앱 539명(44.0%)
- SNS 474명(38.7%)
- 온라인 합계 82.7%는 공식 자료가 직접 제시한 값
- 조건만남 942건(37.9%)은 **피해유형 복수응답 건수**이므로 피해경로 인원과 같은 분모처럼 섞지 않는다.

### 슬라이드 C — 실제 사건
**가출 상태의 숙식 의존이 폭행·협박과 성매매 강요로 이어진 실제 사건이 있다.**

  - https://www.mogef.go.kr/nw/rpd/nw_rpd_s001d.do?bbtSn=711030&mid=news405
  - 2025년 전국 17개 지원센터, 피해아동·청소년 1,226명.
  - 피해 경로: 채팅앱 539명(44.0%), SNS 474명(38.7%), 온라인 82.7%.
  - 피해유형(복수응답): 조건만남 942건(37.9%), 폭행·갈취 289건(11.6%), 디지털 성범죄 280건(11.3%), 길들이기 206건(8.3%).

### 보조
- 2024 거제 사건: 2024.7.24. 창원지검 통영지청 발표를 인용한 언론보도.
- 현재 공개 웹 검색에서 검찰 원문 보도자료 URL은 직접 확보하지 못했으므로, 본편 출처는 확보 가능한 보도기사 층위로 표시한다.

## 4. 금지

- 82.7%를 ‘가출청소년의 온라인 성매매 비율’로 바꾸지 않는다.
- 지원센터 이용자 1,226명을 전체 성착취 피해청소년 규모로 해석하지 않는다.
- 조건만남 942건(37.9%)은 복수응답 피해유형 건수이며, 1,226명과 단순 인원 비교하지 않는다.
- 거제 사건을 일반적 발생률이나 우범소년 송치의 효과 증거로 사용하지 않는다.
