# 제1장 B 사례 수정 기록

- 기준: 같은 폴더의 16쪽 수정안 DOCX A1 및 사용자가 첨부한 사례 화면.
- 수정: 7호 처분에 고려된 부모의 보호 어려움, 부모의 시설처분 요청, B의 치료 필요성 명시. 현행 7호 처분의 뜻 추가. 하단을 페이지 전체 판단 질문으로 교체.
- 근거: 강정은의 직접 수행 사건 보고, 2021.3.9 토론회 인쇄면 18쪽. 법원 결정문으로 소개하지 않는다. 구체 진단이나 법원의 상세 선택 이유를 추정하지 않는다.
- 소년법 제32조 제1항 제7호의 현행 문구를 국가법령정보센터에서 대조했다.
- 디자인: 시간순 3열, 제목·열 구조선, 금색 화살표, 하단 질문 밴드를 보존했다. 세 결과 사정은 굵기로 강조했다. 사용자 화면의 노란 강조 대신 굵기를 사용했다. 하단 서지는 발표자 노트로 옮겼다. 본문 상자는 채움·외곽선이 없다.
- QA: 최종 PPTX 1장 전체를 LibreOffice로 1600×900 렌더했다. 개별 화면과 수정 전후 접촉시트를 직접 확인했다. 글자 잘림·줄 겹침 없음. 열 정렬과 동일 위계 색 일치. 화살표가 본문에 붙지 않도록 조정했다. Pretendard Regular/Bold와 latin·ea·cs 지정, 줄간격 118/125를 확인했다.
- 한계: 이 파일은 수정한 사례 1장이다. 다른 제1장 화면을 변경하거나 전체 제1장을 렌더했다고 기록하지 않는다.
- 재생성 코드의 작업 디렉터리는 현재 작업 환경의 절대 경로다. 다른 환경에서는 base/workspaceDir 경로를 바꿔 사용한다.
