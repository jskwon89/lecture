- 수신 master: `7c16d204f46ee972e05ec77681b28413a80c4c3f`, 2026-09-23 00:59:36 KST.
- 공통 Canonical과 GPT_LAYOUT_EXPERIMENT, 사용자 후속 지시를 적용했다. 키트의 본문 14/12.5pt, 행 내용군 가운데 배치, 제목 칩 없음 기준을 따른다.

- 원래 7장 덱에서 삭제 승인된 ‘논제 안/밖’ 페이지를 제외하고, 남은 6장에 검증된 두 사례 및 세 페이지를 보강하여 11장으로 통합했다. 단순한 장수 유지보다 자료·논거에 맞춘 배치를 요청한 최신 사용자 지시에 따른다.

## 출처를 사용하는 범위

법원 실무자료 사례 7은 결정문 전문이 아니다. B 사건의 7호 사유는 담당 변호사의 보고에 한정하며 진단·대체 치료 선택의 법원 상세 이유는 확인되지 않는다. 지원기관의 송치 계획 중단 사례는 이후 치료 성과를 보여 주지 않는다. 2025년 질적 면접은 전국 빈도나 효과평가가 아니다. 2026년 간담회는 공론화 자료이며 제도 변경 확정 발표가 아니다.

## 재생성

`content.py` → `content.json`; `build.mjs` → `candidate_raw.pptx`; `normalize.py` → `candidate.pptx`; `finalize.mjs` → `generated/`의 검증본. `build_docx.py`는 같은 내용으로 DOCX를 생성한다.

PPT는 `@oai/artifact-tool`, DOCX는 `python-docx`를 사용했다. Pretendard Regular/Bold는 사용자가 제공한 글꼴을 설치하여 사용하며 글꼴 파일은 이 폴더에 복제하지 않는다. Node/Python은 `CODEX_PRIMARY_RUNTIME_*` 환경의 의존성을 이용한다. `finalize.mjs`는 Codex Presentations 스킬 경로가 있는 환경에서 실행한다. 재생성 결과는 `generated/`에 쓰며 전달본을 직접 덮어쓰지 않는다. 검증 결과 JSON도 새 경로에 저장해야 한다.

기존 DOCX 수정안 원본, 교체용 1장/2장 PPT는 이력으로 보존했다. 공통 규칙과 다른 단원의 PPT는 이 작업에서 변경하지 않았다.
