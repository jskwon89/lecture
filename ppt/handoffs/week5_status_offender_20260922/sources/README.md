# Week 5 Source Pack — 우범소년 송치와 성착취 위험

기준일: 2026-09-22  
논제: **성매매가 우려되는 가출 청소년을 우범소년으로 송치하여야 하는가?**

이 폴더는 5주차 강의자료의 **출처·원문 위치·수치 원표·검증상태**를 한곳에 모으기 위한 source pack이다.

## 먼저 볼 파일

1. `CHAPTER_COVERAGE_MATRIX.md` — 8개 단원별 자료 충분성·남은 공백
2. `CHAPTER_SOURCE_MAP.md` — 단원별 실제 자료·가능한 화면·DATA-QA
3. `SOURCE_MANIFEST_v1.md` — 출처 전체 대장, 공식 원문 URL, 사용범위, 재배포 상태
4. `ORIGINAL_SOURCE_LINKS.md` — 원문/원표를 받을 수 있는 공식 링크만 모은 목록
5. `statistics/support_center_2021_2025.csv` — 지원센터 공식 수치 재구성
6. `statistics/status_offender_series_working.csv` — 우범소년 통계 작업표와 DATA-QA 상태
7. `legal/LEGAL_SOURCE_NOTES.md` — 소년법·청소년성보호법·대법원 2025트6의 공식 원문 위치
8. `legal/JUVENILE_ACT_RELEVANT_TEXT_20260922.md` — 소년법 제2·4·18·32조 원문 발췌 보존
9. `legal/YOUTH_SEXUAL_PROTECTION_ACT_RELEVANT_TEXT_20260922.md` — 청소년성보호법 제38·47조의2 및 2020 개정 비교용 원문 발췌

## 원문 보존 원칙

- 정부·법원·연구기관의 공식 원문 링크를 최우선으로 등록한다.
- 원문 파일의 재배포 조건이 명확하고 작업도구가 원본 바이트를 확보할 수 있을 때만 Git에 바이너리를 복제한다.
- 뉴스기사·학술지 논문처럼 저작권 재배포가 허용되지 않은 자료는 원문을 복제하지 않고 서지·공식 URL·확인한 사실·사용범위만 기록한다.
- 공개 PDF라도 단순 공개와 재배포 허용은 다를 수 있으므로, 라이선스가 불명확하면 원문 링크만 둔다.
- 성평등가족부 일부 자료는 공공누리 유형이 명시되어 있다. 제4유형 자료는 출처표시·비상업·변경금지 조건을 지켜야 하므로, 공개 Git에 원본 바이너리를 임의 재업로드하지 않고 공식 원문 링크를 유지한다.
- 현재 도구 세션에서 공식 다운로드 엔드포인트가 application/octet-stream 또는 동적 다운로드로 제공되는 일부 PDF는 원문 존재와 다운로드 URL은 확인했지만 바이트를 안정적으로 가져오지 못했다. 이를 ‘원문 확보 완료’로 표시하지 않는다.

## 데이터 사용 원칙

- 지원센터 이용자 수는 전체 피해자 추정치가 아니다.
- 활동 건수·서비스 건수·피해유형 복수응답 건수와 사람 수를 구별한다.
- 우범소년 ‘접수’, ‘처리’, ‘보호처분’, ‘소년원 입원’을 같은 수치로 취급하지 않는다.
- 법원 최신 수치 가운데 원표 직접 대조가 끝나지 않은 값은 `DATA_QA_HOLD`로 표시한다.
- 직접 효과연구를 확인하지 못한 경우 간접연구로 빈칸을 채워 ‘효과 있음/없음’을 만들지 않는다.
