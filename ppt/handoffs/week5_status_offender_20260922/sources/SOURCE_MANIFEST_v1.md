## 원문 파일 미러링 정책

- **법령·판례·정부/국제기구 원문**: 공식 링크를 고정하고 필요한 조문·판시 위치를 별도 source note에 보존한다.
- **공공누리 제4유형 자료**: 출처표시·비상업·변경금지 조건이 있으므로 이 공개 Git에 원본 PDF를 자동 복제하지 않고 공식 원문 링크를 우선한다.
- **뉴스·학술논문**: 저작권 재배포가 허용되지 않는 경우 원문 파일을 Git에 올리지 않는다.
- **KWDI/KICJ 보고서**: 공식 다운로드 가능 여부는 확인했지만, 재배포 조건이 명확하지 않은 경우 링크만 둔다.
- 현재 세션의 파일 도구는 일부 동적/octet-stream PDF의 raw bytes를 받지 못했으므로, 그런 자료는 `ORIGINAL_SOURCE_LINKS.md`에 원문 다운로드 위치와 미러 상태를 명시한다.
