## Scope

- PPT 뒤쪽 강의대본/발표자 노트/숨김 appendix에는 상세자료집의 원자료 세부, 처분·조치 이유, 용어 해설을 반영한다.
- 실제 PPTX 제작 시 뒤붙임 대본은 슬라이드별로 다음 구조를 사용한다.

## Backmatter page structure

For each slide:

1. 슬라이드 번호·제목
2. 강의 대본
3. 강사용 상세자료
   - 원자료에서 확인되는 구체적 내용
   - 조치·처분 이유 / 근거층위
   - 용어·제도 해설
4. 원자료·출처

## Rationale-level distinction

처분·조치 이유는 반드시 다음 세 층을 구분한다.

1. **사례에 직접 명시된 이유**
   - 예: 학교현장 사례 7의 ‘조건만남 등을 통해 가출 생활을 유지할 가능성이 높음 → 6호 소년보호시설 감호위탁’.
2. **동일 원자료의 일반 운용설명**
   - 예: 『소년 통고 실무』의 ‘반복가출·성매매 + 보호자 생활지도 한계 → 위탁보호위원·보호관찰로 생활지도·감독 가능’.
3. **처분의 법적 기능**
   - 예: 1호 감호위탁, 2호 수강명령, 4·5호 보호관찰, 6호 시설 감호위탁, 7호 의료위탁의 법적 기능.

위 세 층을 섞어 개별 사례가 직접 적지 않은 처분사유를 새로 만들지 않는다.

## Required detailed explanations

- `긴급 소년분류심사원 임시위탁`이라는 표현은 학생용 본문에서 쓰지 않는다. 정식 표현은 **조사 당일 소년분류심사원 위탁 결정(소년법 제18조의 임시조치)**로 쓴다. ‘긴급’은 별도 처분명이 아니라 사건경위 설명이다.
- `쉼터 임시퇴소`는 PPT 화면에서는 **쉼터를 나온 뒤**로 풀어 쓰고, 자료집/대본에서만 원자료 표현이 임시퇴소였음을 설명한다.
- `동행영장`은 소년을 조사·심리하기 위해 법원에 인치하는 영장으로 설명한다. 사례요약이 제13조 일반 동행영장인지 제14조 긴급동행영장인지 특정하지 않으면 그냥 동행영장으로 쓴다.
- `동행영장`과 `소년분류심사원 위탁`은 서로 다른 단계다. 전자는 데려오는 수단, 후자는 데려온 뒤 조사·심리를 위한 임시조치다.
