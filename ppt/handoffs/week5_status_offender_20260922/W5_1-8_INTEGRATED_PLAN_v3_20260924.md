# 5주차 1~8장 통합 구성안 v3 — 2026-09-24

논제: **성매매가 우려되는 가출 청소년을 우범소년으로 송치하여야 하는가?**

## 상태

- 최신 제1장 v10 전 페이지 논제감사를 기준으로 제2~8장까지 다시 연결했다.
- 본편 **57장 안팎 / 약 95~100분**을 기준으로 한 페이지별 강의안·PPT 구성안을 작성했다.
- 각 장은 `NECESSARY BASELINE / DIRECT EVIDENCE / DECISION CONDITION / SYNTHESIS` 역할을 먼저 잠근 뒤 제목·상단·하단을 배치했다.
- 제목만/상단만/하단만 읽는 논제 중심축 감사를 적용했다.
- 학생 화면에는 제작자 메타서술·방어문구를 넣지 않고, 대본은 원자료의 구체적 사건경위·행위주체·개입이유·처분이유를 복원한다.

## 8개 단원과 장수

1. **우범소년은 어떤 경우에 성립하고 어떻게 소년부로 가는가** — 8장
2. **성매매에 유입된 청소년의 법적 지위는 어떻게 달라졌는가** — 6장
3. **가출과 성착취 위험은 실제로 어떻게 연결되는가** — 6장
4. **우범소년 제도는 실제로 어떻게 사용되는가** — 5장
5. **우범소년 송치가 필요하다고 보는 입장과 그 근거** — 7장
6. **우범소년 송치에 문제를 제기하는 입장과 그 근거** — 9장
7. **두 입장의 근거를 실제 자료로 어디까지 확인할 수 있는가** — 10장
8. **주요 쟁점과 각자의 판단** — 6장

## 이번 재구성의 핵심

- 제1장의 ‘두 사례의 처분이 달랐다’는 비교 자체보다 **소년부 경로가 기존 보호에 법원의 감호·상담·보호관찰·시설보호를 추가한다**는 기능을 상위 메시지로 둔다.
- 제2장은 2020 개정의 피해자 지위 전환과 현행 지원경로를 구체적으로 설명하고, 우범소년 경로가 별도로 남아 있다는 접점에서 끝낸다.
- 제3장은 가출을 독립적인 위험 낙인으로 쓰지 않고 **성매매범죄 피해자 내부의 가출상태 분포 + 강요·알선의 높은 비율 + 실제 숙식의존·온라인 접촉 맥락**으로 설명한다.
- 제4장은 접수 → 보호처분 → 강한 처분 → 소년원 입원을 서로 다른 분모로 구분한다.
- 제5장은 반복피해·연락단절·지원중단 상황에서 **왜 강제적 보호수단을 요구하는 논거가 생기는지**를 실제 면접·토론회·7호 사례·법무부 회신으로 구성한다.
- 제6장은 피해자 지위·책임전가·낙인·인권위·UN CRC·헌재·지원기관 협의사례·2026 국민경청회로 문제제기 논거를 구성하되 특정 결론을 강사가 선택하지 않는다.
- 제7장은 피해지원 vs 소년사법의 실제 작동, 대법원 2025트6, 치료경로, 일본·미국·뉴욕, diversion 간접효과, 국내 직접효과 공백, 국내 인프라·수용능력 공백을 검증한다.
- 제8장은 새 자료를 넣지 않고 현행법 적용/제도선택, 공통확인점, 남은 근거공백, 네 판단질문, 유지·조정·복지대체 설계, 학생 자기논증으로 회수한다.

## DATA-QA

- 2024·2025 우범소년 최신 접수수치는 법원 원표 직접대조 전 메인 그래프에서 제외.
- 2023 세부 보호처분 수치는 사법연감 원표 또는 공식 재인용 자료 최종대조 후 화면 확정.
- 2017~2023 피해 당시 가출 수치는 성매매범죄 피해자 N=2,943를 분모로 유지하며, 가출청소년 전체의 성매매 피해율로 바꾸지 않는다.
