> 이제 이러한 제재 강화가 필요한지 논의하기 위해 실제 피해를 살펴보겠습니다. 다음 장에서는 학교폭력의 발생 실태와 함께, 피해학생이 등교하거나 수업에 참여하는 데 어떤 어려움을 겪는지 알아보겠습니다.

화면 맨 아래 “조치를 빨리 이행하고 상담·학습 지원을 늘리는 것도 피해 회복에 중요하다”는 문장은 피해학생 지원을 설명하는 4장으로 옮기는 편을 권했다. 제목·대본·이 문장 이동은 채팅 수정안이며 최신 PPT 반영 여부는 확인하지 않았다.

## 6. 2장 현재 구성과 검토 포인트

| 내용 번호 | 주제 | 검토할 점 |
|---|---|---|
| 2-1 | 피해응답률과 최근 추이 | 조사 참여학생이 분모. 응답기간·조사기간·대상·반올림 인원 구분. 검거·심의 사건 수로 설명하지 않음 |
| 2-2 | 주요 피해 유형 | 유형 응답 건수 비중과 학생 비율 구분. 주요 4유형 발췌를 전체 분포처럼 만들지 않음 |
| 2-3 | 경기 피해 발생 장소 | 전국에서 경기 자료로 전환하는 이유를 짧게 설명. 학교 밖에 사이버공간 포함. 발생 비중을 피해 심각성 차이로 바꾸지 않음 |
| 2-4 | 쉬는 시간·점심시간의 피해 | 시간 응답 건수 기준이며 장소와 별개 분포. 교실 비율과 곱하거나 피해자 수로 합산하지 않음 |
| 2-5 | 두 상담기록의 학교생활 어려움 | 서로 다른 학생·보호자 기록. 신원 보호를 위한 일부 각색. 보호자의 걱정과 실제 확인 결과 구분 |

- 기존 v20의 “피해 확인 가이드라인”은 **4장으로 이동**했다. 2장 끝에 다시 넣지 않는다.
- 학교급별 수치는 강사용 상세자료로 이동했다. 다시 늘릴지는 화면의 설명 목적에 따라 판단한다.
- 2장 말미는 학교에 출석해도 편히 쉬거나 또래와 지내기 어렵다는 경험에서 3장 “학교가 보호해야 할 안전과 교육”으로 이어진다.
- 1장의 도입 보도·교실/공원 가상 사례·정의를 반복하지 않는다.
- 통계 수치의 출처·확인 범위는 기존 SOURCE_NOTES를 먼저 활용한다. 이 인계 작성은 통계 원표의 새로운 전면 검증을 뜻하지 않는다.
- 실제 사례의 처분·발생 장소·회복 경과가 원문에 없으면 덧붙이지 않는다.
- 교내 가중의 직접 주장, 인접 논거, 강의용 찬반 논증의 구별을 유지한다.
- 자료 보강은 남은 구체적 질문에 맞춰 한다. 새 장을 검토할 때마다 이미 조사한 모든 자료를 처음부터 수집하지 않는다.
