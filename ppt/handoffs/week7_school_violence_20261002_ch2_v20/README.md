전국 조사 2026년 1차의 대상·참여율·경험 기간·피해응답률·유형 응답 분모를 확인했다. 장소·시간은 세부 원표 전체를 읽을 수 있는 2026년 경기 자료를 사용하며 학생 화면 제목과 메타정보에서 지역 범위를 밝힌다. 학교밖 항목에 사이버공간이 포함된다는 조건도 유지한다. 도입의 두 보도나 교실·공원 가상 비교는 반복하지 않는다.

도입·1장 내용은 v19를 유지한다. 학교의 보호이익·공동생활·판결은 3장, 접촉금지·분리·집행·지원은 4장, 제재·교육 효과와 김현주 교사 사례는 5장에서 처음 설명한다. 7장은 쟁점별 두 입장의 주장과 앞의 근거 정리다.
