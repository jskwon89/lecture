3장 학교가 보호해야 할 안전과 교육은 학생의 권리→피해 뒤 공동생활→수업 중 접촉 사건→대법원의 판단 이유→학교의 보호 책임과 행위 책임의 구분으로 구성했다. 교육기본법 제12조 제1항 전문을 제시하고 헌법재판소와 대법원의 실제 판단 이유를 원문 대조했다. 판결을 시설 안팎의 형량 차등을 직접 주장한 자료로 바꾸지 않는다. 사실과 법원의 평가, 강의용 논제 연결을 구분한다.

2장은 학교급별 수치를 강사용 자료로 이동하고 장소 분포와 생활 피해의 연결을 보완했다. 상담기록 두 건의 독립성 및 보호자의 걱정과 확인된 결과를 구분했다. 가이드라인은 4장에서 지원 방법과 함께 처음 설명하도록 옮겨 5개 화면으로 줄였다. 이동 화면 전체와 출처는 JSON relocations에 보존했다.

전체는 도입과 7단원을 유지한다. 도입·1장은 v19, 2·3장은 이 v21이 현재 내용 기준이다. 4장에서는 v19에서 이동한 심의 전 접촉금지·분리·보호 경로와 이번에 옮긴 가이드라인을 처음 소개한다. 5장의 김현주 교사 사례, 6장의 차등 기준·권리, 7장의 쟁점별 두 입장의 주장과 근거 정리는 유지한다.
