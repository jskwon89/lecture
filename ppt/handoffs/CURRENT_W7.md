## 이미 합의한 설명 방식

- p.1~2 실제 보도는 피해 뒤 교실 출입·등교·학교생활의 어려움까지 보여 주는 사례로 고른다. 서로 다른 실제 사건을 처분 차이의 비교실험으로 만들지 않는다.
- p.3은 교실·공원 비교로 논제를 한 번 이해시키는 장이다. 추상적인 `추가 무게`, 인물 A·B 이름, 반복 적용 표시는 쓰지 않는다.
- p.4는 **어디에서 발생했는지 / 어떤 활동 중이었는지 / 사건 뒤 학교생활에 어떤 어려움이 생겼는지**를 구분한다. 체험학습은 시설 밖 교육활동, 방학 운동장의 사적 만남은 시설 안이지만 교육활동과의 연결이 약한 예다.
- 다음 개념·제도 장에 같은 A·B 사건을 반복하지 않는다. 각 페이지는 필요한 실제 내용과 개념 예시로 설명한다.
- 화면·낭독 대본은 쉽게 이어 말하고 같은 조건·논제 설명을 여러 번 하지 않는다. 핵심 사실·조치·판단 이유와 정확한 법적 명칭은 보존한다. 추가 자료·출처·검토 메모는 구역을 나눈다.
- 판결의 실제 판단, 발표자의 실제 입장, 이를 근거로 강의에서 구성한 논증을 구분한다. 직접 국내 교내/교외 가중 주장의 미확인을 부재로 선언하지 않는다. 교내라는 사실이 판결에 등장했다고 교외보다 더 중하게 처벌하라는 판시로 바꾸지 않는다.
- 학생용 출처 각주는 생략하며 상세 출처·원문 위치를 노트·자료대장에 보존한다. 법조문·사건번호·시점·분모 등 이해에 필요한 정보는 관련 본문에서 설명한다.
