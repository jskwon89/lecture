# v18 검증 기록

- 학교폭력예방법 제2·17조, 시행령 제19조, 형법 제9·51조의 국가법령정보센터 조문 원문과 시행일을 2026-10-02 다시 확인했다.
- 정의와 사이버폭력 발췌의 생략 부분을 표시했다. 소년법·세부 고시·가이드북의 추가 확인 상태를 완료로 바꾸지 않았다.
- 제17조 목적·퇴학 예외·병과·협박 및 보복의 가중을 서로 다른 위치에 연결했다. 심의 전 조치 경로는 4장 이동을 유지한다.
- 형법 제51조의 4개 항목과 시행령 제19조의 5개 항목이 원문의 순서와 문구에 대응한다. 보호자 간 화해와 피해학생의 장애 여부를 임의로 줄이지 않는다.
- 원문은 MD 한 곳에 보관하고 JSON에는 대응 블록 ID를 둔다. 화면 설명과 낭독 대본은 원문 인용과 분리했다.
- 9개 삽입 블록, 고유 블록 ID, 5개 출처 ID를 검사했다. v17의 사용자 동의 방향과 실제 파일 편집 상태를 구분했다.
- 실제 전체 DOCX·PPTX 편집·노트·렌더 검수를 완료한 것으로 표시하지 않는다. 이전 v15·v16·v17 원본, 공통 규칙·도구·디자인 변경 없음.
- 파일 SHA256은 앞 작업에서 표준 검증값과 기존 Python 산출 UTF-8 파일 해시를 대조한 JavaScript 계산으로 작성한다. 원격 조회 원문과 MANIFEST를 대조한다. 연결되지 않은 실행 환경에서 sha256sum 명령을 실행했다고 표시하지 않는다.
