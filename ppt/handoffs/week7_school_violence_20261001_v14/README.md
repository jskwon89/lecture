# W7 v14 화면 문구·간결한 낭독 대본 — 검토용 수정안

논제: 학교 안에서 발생한 학생 간 폭력은 학교 밖에서 발생한 청소년 간 폭력보다 중히 처벌되어야 하는가?

작성: 2026-10-01 / Git 반영: 2026-10-02. **29장 수정 제안이며 실제 PPTX는 아직 수정하지 않았다. 전체 주차 최종본이 아니다.** `ppt_revision_v14.json`과 `SOURCE_MAP.md`는 앞서 작성한 v14 파일의 바이트를 그대로 보존했다. JSON의 `git_commit`은 수정안 작성 당시 검토한 커밋이며 이번 반영 커밋을 뜻하지 않는다.

현재 상태·다음 목차 방향은 [CURRENT_W7.md](../CURRENT_W7.md)를 먼저 읽는다. 공통 제작 기준은 `ppt/current/README.md`에서 시작한다.

## 기준과 페이지 대응

- 실제 기준 파일: `W7_도입_1장_2장전반_v12.pptx`, 25장.
- SHA-256: `29275d3d0ff23cf70591060a7fbf906338edfe792999707ca639c9b2b0f503fc`.

## 반영 방법

- 화면에는 JSON의 `title`·`band`·`body`를 쓴다. 새로운 설명 없이 같은 내용을 반복하는 `closing`은 만들지 않는다. 승인 디자인·필수 화면 정보는 유지한다.
- `script`는 낭독용 설명, `speaker_notes`는 낭독용 대본·출처·내부 제작 메모로 나뉜 기존 노트 문안이다. `SOURCE_MAP.md`에서 출처의 서지·URL·확인 위치를 대응시킨다. 추가 질문 대응·전문적 맥락을 보완할 때는 강사용 상세자료 구역을 별도로 만든다.
- 가상 교실·공원 비교는 p.3에서 한 번 사용한다. p.4는 시설·교육활동의 개념 예시로 설명하며 이후 장에 A·B 적용 문단을 되살리지 않는다.
- `next`는 연결 확인용이다. 실제 NEXT는 현재 디자인 규칙에 맞추되 같은 긴 문장을 화면 하단과 낭독 대본에 자동으로 반복하지 않는다.
- 실제 사례·판결·토론회 발언과 강의용으로 구성한 논증을 구분한다. 원자료 확인 범위는 SOURCE_MAP에 남아 있으며 이번 Git 지침 작업에서 법령·판례를 새로 조사한 것은 아니다.
- p.26~29는 기준 선택·공개논의·해외제도·종합의 초안이다. 다음 단원을 조사·구성한 뒤 위치와 근거를 다시 점검한다. 아직 없는 효과·비용·권리 검토가 끝난 것처럼 최종 종합을 확정하지 않는다.
- 실제 반영은 도입·1장부터 검토하고, 2장과 이후 단원의 사용자 검토 상태를 구별한다. 새 PPTX를 만든 뒤 화면·노트 대응과 전 장 렌더·수정 전후 비교를 확인한다.
