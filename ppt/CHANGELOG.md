# PPT 규칙 변경 이력

## 2026-09-18 · Git Canonical v1.0

기존 프로젝트 소스와 같은 날 대화에서 확정한 규칙을 Git 기준으로 통합했다.

핵심 변경:

- `guideline_v11.1`, `standard_structure_v4`, `ops_handbook_v4`, 운영 정합성 문서를 `source_rules/`에 원문 보존
- 기존 디자인·QA 수치와 부록까지 `PPT_RULES.md`에 통합
- 제목은 **간결한 표제형 핵심내용**을 우선하도록 확정
- 문맥상 자명한 대상·조건은 제목에서 생략
- 주체는 필요할 때만 실제 행위의 주체를 사용
- 연구자가 만든 조건을 제도 자체의 행위처럼 쓰지 않음
- 연구 원문을 충분히 읽고 실제 개입·비교집단·결과를 구체화
- 대상/비교집단/결과가 다른 위계이면 같은 열에 병렬 배치하지 않음
- 처음 나오는 제도·약어는 정의·작동방식을 먼저 제시
- 연구설계와 결과가 과밀하면 두 장으로 분리
- %/%p/상대변화/hazard/OR/RR 등 수치의 실제 의미를 설명
- 논제와 직접성이 낮은 연구는 본편 비중을 낮추거나 부록·대본으로 이동
- 제작·배치·QA 도구와 skeleton을 Git에 함께 보존
- 성숙 참조 덱을 `references/`에 등록
- Claude 독립 감사 프롬프트 추가

### Supersede

`guideline_v11_1_20260918.md`의 `명확한 주체가 있으면 제목 맨 앞에 반드시 둔다`는 규칙은 **현행 Canonical의 제목 압축·실제주체 원칙으로 대체**한다.
