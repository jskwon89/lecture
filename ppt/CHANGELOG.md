## 2026-09-19 · Git Canonical v1.4 — 비교정책·효과자료의 논제-선택지 구조 강화

청소년 마약 효과자료의 대안 시안을 비교·재구성하면서, 정확성을 높이려다 연구를 한 장에 과밀하게 넣는 문제와 결과변수 중심 분류가 논제의 처우선택을 가리는 문제를 규칙화했다.

- `references/COMPARATIVE_EFFECT_SLIDE_DESIGN_LESSONS_20260919.md` 신설
- 비교 논제에서는 결과변수보다 먼저 **논제의 정책·처우 선택지**를 분리하도록 Canonical 보강
- **한 장 = 한 가지 논리**를 기본값으로 하고, 제작 전 “학생이 기억할 한 문장”을 잠그도록 규정
- 개별연구·메타분석·간접근거·사후지속성을 같은 장에 자동 병합하지 않고 역할별로 분리
- JDTC 등 결합형 처우를 치료/처벌 어느 한쪽의 순수효과로 배분하지 않도록 명시
- 최종 비교표에서 프로그램 목표와 관찰효과를 같은 급으로 놓지 않고, 직접근거가 없으면 **근거 부족을 그대로 표시**하도록 규정
- WORKFLOW에 정보위계 게이트보다 앞선 **논제-역할 게이트** 추가
- 레이아웃보다 `논제 선택지 → 장의 한 문장 → 최소근거 → 실제 결과 → 한계 → 다음 연결`을 먼저 확정하는 순서 추가
