# PPT 규칙 변경 이력

## 2026-09-18 · v0.1

초기 Git 기준 생성.

반영한 핵심 논의:

- 화면만으로 이해 가능한 구체적 문안
- 제목은 긴 설명문보다 핵심만 남긴 표제형을 우선
- 문맥상 자명한 대상·조건은 제목에서 생략
- 주체가 필요하면 실제 행위의 주체만 사용
- 연구자명·표본수·무작위배정 등 방법론을 제목의 중심으로 두지 않음
- 연구 원문을 충분히 읽고 실제 개입·비교집단·결과를 구체화
- 대상/비교집단/결과가 다른 위계이면 같은 열에 병렬 배치하지 않음
- 제도·약어는 정의 후 비교
- 연구설계와 결과가 과밀하면 두 장으로 분리
- %/%p/hazard 등 통계량의 실제 의미를 화면·대본에서 설명
- 오늘 논제와 직접성이 낮은 연구는 본편 비중을 낮춤
- 최종 참조본을 Git에 등록해 이후 디자인·정보위계 참고자료로 사용
