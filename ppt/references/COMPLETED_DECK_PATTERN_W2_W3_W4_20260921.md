- **관찰:** 파일에 실제 들어 있는 목차·문구·배치·자료의 역할을 분석한다.
- **사용자 확정 방향:** 이 대화에서 사용자가 직접 교정한 제목, 주장·근거, 그래프, 조사 순서를 반영한다.
- **다음 제작 지침:** 좋은 구성은 재사용하되 남아 있는 오류·중복·미검증 문구는 재사용하지 않는다.

원본 강의자료의 모든 법령·통계·사실을 2026-09-21 현재 다시 검증했다는 의미는 아니다. 원자료의 주장과 이번 분석의 해석을 구별한다. 수치 재사용 시 원자료를 다시 확인한다. 좌표·색·폰트는 `PPT_RULES.md`와 도구가 기준이며 이 문서에서 역산하지 않는다.

## 1. 세 주차의 공통 구조 — 입장 나열보다 판단에 필요한 자료를 먼저 제공한다

공통적인 흐름은 다음과 같다.

> 논제의 대상과 바꾸려는 것 → 현행 법·제도의 기준선 → 실제 처리와 생활에서 생기는 문제 → 필요한 비교·대안·효과자료 → 쟁점별 주장과 근거 → 학생의 최종 판단

다만 세 주차를 동일한 목차로 만들지는 않았다.

| 주차 | 논제가 바꾸려는 것 | 자료를 읽는 중심축 | 고유한 구성의 장점 |
|---|---|---|---|
| 2주차 | 사형이라는 형벌의 법적 존치 여부 | 형벌 목적·생명권·대체형벌·추가효과·오판 | 철학적 이유, 법적 판단, 효과연구, 유족·여론을 서로 다른 종류의 판단재료로 제시 |
| 3주차 | 형사책임을 물을 수 있는 연령·사건 범위 | 기존 보호체계에 형사책임 경로를 추가하는 변화 | 현행 절차와 변경 후 절차를 구별하고, 운영 문제와 연령선 변경이 해결하는 문제를 대조 |
| 4주차 | 투약·사용 청소년에 대한 기본 대응의 우선순위 | 사법처리 경로·치료의 실제 내용·제공 여건·효과 | 제도와 서비스를 분리해 설명하고, 국내 실제 사례·프로그램·기관 실적을 논제의 실행조건으로 연결 |

2주차의 철학·헌법 중심 구조를 그대로 4주차에 복사하거나, 4주차의 기관·서비스 순서를 모든 주차에 강제하지 않는다. **변경하려는 정책과 학생이 먼저 알아야 할 관계**에 따라 목차를 구성한다.

## 2. 목차는 자료의 학습 순서이고, 쟁점은 최종 판단 질문이다

### 2-1. 2주차의 관찰

목차(W2 p.3)는 다음 여섯 구간이다.

1. 사형은 어떤 형벌이며 왜 두는가
2. 사형 규정과 절차의 역사적 변천
3. 현행법과 집행 현실
4. 국제 비교
5. 헌법재판과 대체형벌
6. 자료읽기 — 비용·억제효과·오판·여론·유족

실제로는 p.4~7에서 형벌 목적과 폐지의 의미를 정하고, p.8~15에서 역사·현행·국제 상황, p.16~35에서 헌법재판과 대체형벌, p.36~45에서 비용·효과·오판·유족·여론을 다룬다. p.46~48에서야 자료를 논거로 다시 정리한다.

**재사용할 점:** 주장의 근거가 실험논문일 필요는 없다. 칸트·베카리아의 형벌관(p.4), 헌재와 공개변론의 논거(p.20~27), 효과연구(p.37~39), 여론 문항과 응답(p.44~45)은 서로 역할이 다르다.

### 2-2. 3주차의 관찰

목차(W3 p.2)는 다음 여덟 구간이다.

1. 형사책임연령과 현행 대응
2. 응보·예방·보호와 현행제도의 한계
3. 공론화와 세 정책대안
4. 연령 기준의 설계와 법적 한계
5. 연령 하향의 범죄예방 효과
6. 발달과 조사·재판의 권리보장
7. 소년사법 개선과 피해자 보호
8. 주요 논거와 최종 판단

p.3~20의 법·처분·기록·통계가 기준선이고, p.21~30에서 그 체계의 운영과 권리 문제를 설명한다. p.31~37의 공론화·대안을 거쳐 p.38~53에서 설계요건·헌재·국제비교, p.54~58에서 효과·발달·개입을 본다. p.59~61은 네 판단 질문으로 회수하고 p.63부터 보충자료다.

**재사용할 점:** p.21의 ‘현재 문제 / 연령 하향이 바꾸는 것’ 비교는 운영상의 부족을 곧바로 형사책임 확대의 근거로 바꾸지 않게 한다. p.31~36은 시민숙의, 협의체 권고, 정부 검토를 한 산출물처럼 합치지 않는다.

### 2-3. 4주차의 관찰 — 최종 64장·7개 단원·6개 쟁점

| 현행 목차(W4 p.2) | 실제 범위 | 학생이 이 구간에서 알아야 하는 것 |
|---|---|---|
| 1. 청소년 마약류 사용과 현행 대응 | p.3~15 | 누구의 어떤 사용행위를 논의하며, 검찰·소년부·형사법원과 치료서비스가 어떻게 연결되는가 |
| 2. 청소년 마약류의 실태와 사용 맥락 | p.16~25 | 단속 규모, 접촉·사용의 경로, 사용과 공급행위의 중첩, 도움요청 지연. p.17은 본문 중간의 보충표시 장이지만 실제 강의 흐름 안에 배치되어 있다 |
| 3. 형사처벌과 보호처분의 운영 | p.26~30 | 실제 처리통계와 소년의 형 선고·집행 특례 |
| 4. 청소년의 특성과 처우 | p.31~33 | 또래 상황·가정과의 관련성, 청소년기 사용문제와 성인기 경과 |
| 5. 치료·재활 우선의 조건과 한계 | p.34~44 | 국내 프로그램, 참여·완수, 대상 선정, 의무 위반, 치료 제공여건과 사후지원 |
| 6. 형사처벌과 치료·재활의 효과 | p.45~57 | 특별예방·일반예방의 구분, 결합형 법원·치료 경로, 무작위·종합·국내 성인 연구, 지속성·부작용 |
| 7. 주요 논거와 최종 판단 | p.58~64 | 여섯 쟁점 지도 1장 + 쟁점별 주장·근거 6장 |

p.58의 여섯 쟁점은 ① 책임을 묻는 방식 ② 특별예방 ③ 일반예방 ④ 학교생활·사회복귀와 자유 제한 ⑤ 치료 제공과 지속 여건 ⑥ 불참·반복 위반 대응이다. 실제 상세 장의 순서는 p.59~64에서 ①②③⑤④⑥으로 배치되어 있어 쟁점 지도와 상세 순서가 완전히 일치하지 않는다. **다음 제작에서는 쟁점 지도와 상세 장의 순서를 맞추거나, 의도적 순서 변경이면 연결단서로 이유를 보여준다.**

현재 64장에는 별도의 최종 답안 작성 화면이나 마무리 공지 장이 없다. 따라서 “완성본의 실제 구현”과 향후 권장구조를 구별한다. 4주차는 7개 단원과 6개 쟁점이며, 단원 수·쟁점 수·슬라이드 수를 혼용하지 않는다.

### 2-4. 다음 주차 목차를 만드는 규칙

- **단원 수, 쟁점 수, 슬라이드 수를 구별하라.** 4주차는 7개 단원과 4개 쟁점이며 하나의 쟁점이 반드시 한 슬라이드일 필요도 없다.
- 6~8개 단원은 관찰된 유용한 범위이지 고정 할당량이 아니다.
- 목차 왼쪽은 단원명, 오른쪽은 그 구간에서 실제 다룰 자료·개념을 짧게 적어라.
- 목차에 쓴 범위가 실제 본문에 있는지 확인하라. 국내 자료만 있는 구간을 ‘국내외 통계’로 표시하지 마라.
- 단원명과 키커를 일치시키고, 재배열 뒤 NEXT도 바꿔라.
- 목차가 처음부터 특정 결론을 전제하지 않게 하라. 마지막에는 앞 자료를 정책 선택의 이유로 회수하라.

### 2-5. 실제 완성본으로 본 분량 캘리브레이션

세 실제 PPTX의 장수는 다음과 같다.

| 주차 | 총 장수 | 본편 | 보충 | 종합·판단 구간의 실제 배치 |
|---|---:|---:|---:|---|
| W2 사형제 | 50 | 50 | 0 | p.46 자료/판단 구분 → p.47~48 종합 → p.49 자료읽기 → p.50 마무리 |
| W3 형사책임연령 | 85 | 62 | 23 | p.59~61 주요 논거·네 물음 → p.62 마무리 → p.63~85 보충 자료 |
| W4 청소년 마약 | 64 | 64 | 별도 후반 보충구간 없음 | p.58 여섯 쟁점 지도 → p.59~64 쟁점별 주장·근거 |

이 관찰에서 다음 제작 원칙을 둔다.

- **50~64장 본편은 현재 완성본의 관찰 범위이지 목표 할당량이 아니다.** 주제 복잡도와 실제 설명에 필요한 장수로 정하고, 장수를 맞추기 위해 자료를 쪼개거나 합치지 않는다.
- **긴 자료는 본편을 무한히 늘리기보다 보충으로 이동할 수 있다.** W3는 본편 62장 뒤에 23장 보충을 두어 핵심 흐름과 질문 대응 자료를 분리했다.
- **종합·학생 판단 구간은 최소 3장 이상을 먼저 확보한다.** 실제 완성본에서는 W2가 4장 이상, W3가 3장, W4가 7장을 사용했다. 정확한 장수보다 ‘앞 자료를 논거로 회수하는 시간’을 보호하는 것이 핵심이다.
- **슬라이드 수로 강의시간을 직접 환산하지 않는다.** 짧은 전환·목차 장, 1분 법령·통계 장, 2~4분 연구·판례 장, 질문·토론 장의 시간이 다르다. 대본과 실제 리허설 시간을 함께 본다.
- **본편 60장 안팎이 필요해도 한 장의 정보량을 과밀하게 늘리지 않는다.** W3·W4처럼 하나의 법·연구·사건을 ‘구조/결과’, ‘경위/판단’, ‘개입/효과’로 나누는 방식을 우선한다.

| 실제 활동·프로그램 | W3 p.70~71, W4 p.33~35·47·51 | ‘치료’라는 이름을 참가자가 받는 활동으로 구체화 | 운영 안내·프로그램 목표를 검증된 효과로 바꾸지 않음 |
| 개별 효과연구 | W3 p.54~55, W4 p.45~48·51·53·55 | 특정 처우와 실제 비교경로 사이의 결과 | 치료구성의 차이를 치료 대 형사처벌의 직접 비교로 바꾸지 않음 |
| 연구 종합 | W2 p.37~39, W3 p.58·66, W4 p.49~50·54·56 | 연구 간 공통점·차이와 평균 결과 | 유의하지 않은 결과를 정확히 효과 0 또는 완전한 무효로 바꾸지 않음 |
| 이론·규범·개념 | W2 p.4·6·47~48, W3 p.59~61, W4 p.58~61 | 책임·비례·권리·예방·자원배분에 관한 판단 이유 | 실증자료가 없다고 논거 자체를 삭제하거나, 가치명제를 검증된 사실처럼 제시하지 않음 |
| 비용·경제성 | W2 p.36; W4 비용 자료는 대화 보완안 및 p.61의 인용 | 추가 비용과 성과, 예산부담과 비용효과성의 구별 | 비용 증가를 곧바로 비효율 또는 다른 정책의 우월성으로 바꾸지 않음 |

**국내 보도와 정부발표는 연구보다 덜 중요한 장식물이 아니다.** 대상자가 무엇을 겪고 담당기관이 무엇을 했으며 제도의 어느 단계에서 문제가 생기는지 보여주는 핵심 자료가 될 수 있다. 대신 기사에 등장하는 기자의 해석, 수사기관의 발표, 당사자의 진술, 판결의 판단을 구별해야 한다.

## 4. 4주차에서 강화된 핵심 — 사법경로와 실제 서비스를 분리한다

W4 p.8~15에는 검찰의 조건부 기소유예, 소년부의 보호처분, 형사법원의 형 선고와 별도로 치료보호·사회재활 서비스가 등장한다. 이 구조에서 추출할 제작 원칙은 다음과 같다.

1. **어느 절차인지 먼저 보여라.** 전체 처리경로에서 현재 화면의 위치를 확인한 뒤 해당 프로그램을 확대한다. 현재 p.8 세부 연계모델보다 p.9 세 갈래 도식을 먼저 설명하는 편이 학습 순서상 자연스럽다.
2. **누가 처분하고 누가 서비스를 제공하는지 나눠라.** 사법기관의 결정과 병원·재활기관의 서비스를 같은 단계처럼 표시하지 않는다.
3. **같은 이름이라도 법적 근거와 실제 내용을 확인하라.** 보호관찰·수강명령을 치료우선 또는 형사처벌우선 중 어느 입장의 전유물처럼 다루지 않는다.
4. **분기는 서열이 아니다.** 조건부 기소유예→소년부→형사재판을 모든 사건이 순서대로 통과하는 단계나 무조건 더 무거워지는 서열로 그리지 않는다.
5. **별도 체계와 연계 지점을 보여라.** 자발적으로 이용 가능한 치료·재활 체계와 사법절차의 의뢰·참여조건이 연결되는 위치를 설명한다.

이 원칙은 소년사법 외의 강의에서도 ‘정책 결정 / 집행기관 / 서비스 제공 / 대상자 경험’의 구분으로 재사용할 수 있다.

## 5. 제목·밴드·본문·하단은 서로 다른 일을 한다

### 제목

제목은 장의 핵심내용을 압축한다. 대상이 문맥상 자명하면 반복하지 않으며, 필요한 주체는 실제 행위자만 적는다.

관찰된 유용한 예:
- W2 p.34: `대법원 — 추가 무기형의 문제만으로 사형을 택할 수 없다`
- W3 p.7: `13세가 범죄소년이 되면 경찰 이후 절차가 어떻게 달라지는가`
- W4 p.9: `마약류 사용 범죄소년의 검찰 송치 이후 과정`
- W4 p.47: `소년약물법원 감독과 MST·CM을 달리 조합한 네 처우경로`
- W4 p.35: `RISKIT-CJS — 전체 완수는 19.1%, 추가효과는 확인되지 않았다`

연구자가 배정한 비교조건을 ‘소년약물법원이 실험했다’는 제도의 행동으로 쓰지 않는다. 제목이 연구자명·표본수·방법명으로 끝나지 않게 하고, 이 정보는 별도 연구라벨로 내린다.

### 상단 밴드

이 장을 이해하는 핵심 관계나 비교범위를 설명한다. 제목을 다시 길게 풀어 쓰거나 ‘이것을 알아야 한다’는 제작 지시문을 넣지 않는다. 쟁점 장에서는 논제 안의 판단 질문을 분명하게 제시할 수 있다.

### 본문

한 화면에서 필요한 주체·조건·행동·결과가 완결되게 한다. 낱말만 압축한 `연계 / 관리 / 지원 / 효과`보다 누가 누구에게 무엇을 하는지 적는다. 반대로 비교의 이해에 필요 없는 제도 전체 설명을 매번 반복하지 않는다.

### 하단

자료가 무엇을 의미하는지 또는 다음에 무엇을 판단해야 하는지 한 문장으로 회수한다. 본문과 상단을 세 번째로 반복하지 않는다. ‘따로 봐야 했다’보다 실제 차이·결과·남는 선택을 쓴다.

### 출처와 표시본

최하단 각주를 지우라는 사용자 지시는 표시본 편집 요구로 적용한다. 본문의 연구명·필수 분모·측정기간까지 지우거나 근거 관리 자체를 중단하지 않는다. 원본 출처, 노트, 자료대장 가운데 추적 가능한 기록을 남기고, 실제로 보존했는지 확인한다.

## 6. 자료유형별 화면 레시피

### 6-1. 법·제도·처리경로

`정확한 개념 → 대상·요건 → 결정주체 → 가능한 분기·결과 → 논제의 변화` 순서다. 원문 조문과 설명용 도식을 구별한다. 대상·비교경로·결과가 서로 다른 위계면 같은 열 제목으로 놓지 않는다.

### 6-2. 사건·판례

`어떤 사건인가 → 어떤 절차와 조치를 거쳤나 → 무엇이 문제였나 → 누가 무엇을 판단했나 → 왜 이 논제에서 중요한가`로 채운다. W2 p.33~34, W3 p.40~42, W4 p.37~38의 역할 분할을 참고한다. 긴 사건은 경위와 판단을 나누고, 같은 사건을 불필요하게 다시 소개하지 않는다.

### 6-3. 통계·조사

숫자에 앞서 또는 바로 옆에 대상·기간·분모·단위를 붙인다. W4 p.20의 ‘6명’은 퍼센트보다 중요한 해석조건이며 p.42의 3.1%는 전체 이용자 중 10대 구성비다. 숫자의 크기만 키우고 분모를 작게 숨기지 않는다.

W2 p.44~45처럼 문항·선택지와 결과를 연결한다. 두 조사를 비교할 때 문항과 응답대상이 다르면 ‘차이가 보인다’는 인상을 곧바로 연령효과로 해석하지 않는다.

### 6-4. 프로그램과 개별 연구

`실제 활동·빈도·기간 → 비교집단의 실제 서비스 → 결과지표와 관찰시점 → 수치와 의미`를 제시한다. W4 p.34~35는 같은 프로그램의 설계와 전달·결과를 구분한다. p.47~48은 네 조건의 구성과 결과표의 세 조건을 구별해야 한다. 앞에서 두 연구가 이어지면 첫 등장에 저자·연도를 적어 연구 경계를 드러낸다.

### 6-5. 연구 종합과 지속성

`무슨 연구를 모았는가`와 `무엇이 나타났는가`가 각각 설명을 요구하면 두 장으로 나눈다(W4 p.49~50). 등록·참여·완수는 운영 결과이고 재사용·재범은 효과지표다. 감독 중과 종료 후 결과는 구분하지만, 서로 다른 표본의 평균을 동일 개인의 효과가 사라진 것으로 단정하지 않는다.

### 6-6. 비용

비교경로·포함 비용·시점·성과단위를 먼저 적는다. 프로그램 예산, 비용 대비 성과, 총비용의 절감을 한 결과로 합치지 않는다. 4주차에서 비용을 쟁점④에 포함한 것은 이 논제의 구성 결정이지 다른 주차에서도 경제성을 독립 쟁점으로 다루지 말라는 뜻이 아니다.

## 7. 그래프 제시 — 문장 나열을 바꾸되 데이터를 새로 만들지 않는다

사용자는 수치가 있는 비교 화면의 ‘내부 내용을 그래프로’ 제시하도록 명시했다. 숫자와 텍스트 상자를 놓는 것만으로 그 요구를 충족했다고 보지 않는다.

- 시계열은 연도축을 가진 선·막대로, 범주별 빈도는 막대로, 실제 단계는 흐름도로 제시한다.
- 막대에는 수치와 단위를 직접 붙이고, 같은 비교범위에는 같은 축을 쓴다.
- 연구·조사별 범주 정의가 다르면 별도 패널로 나누고 원래 항목명을 유지한다.
- 복수응답, 서로 겹칠 수 있는 범주를 근거 없이 더하지 않는다.
- 제시되지 않은 값을 0으로 채우지 않는다. 미확인·미측정과 0을 구별한다.
- 66.7처럼 퍼센트 단위로 입력한 값에 비율용 퍼센트 서식을 적용해 6,670%가 표시되지 않도록 단위와 서식을 함께 확인한다.
- 차트를 만들면 제목·범례·데이터·축·라벨·본문 설명을 서로 대조한다. 수치의 설명을 아래에 같은 길이로 다시 나열해 그래프의 공간을 빼앗지 않는다.

**W4-chart 재사용 판정:** 그래프화 요구의 사례로는 포함한다. 다만 제작 코드와 차트 데이터에는 청소년의 텔레그램·온라인 항목을 66.7로 합산하고, 원본 화면에서 확인되지 않은 약국·병의원 항목을 0으로 넣은 부분이 있다. 항목의 상호배타성과 실제 0을 원표로 확인하지 않은 상태에서 이 통합 비교를 검증된 수치로 재사용하지 않는다. 성인조사 출처 명칭과 의료적 사용 포함 범위도 재확인 대상이다. 이는 이 분석이 보류한 사항이며, 이번 작업에서 그래프를 수정했다는 뜻은 아니다.

## 8. 네 쟁점에서 배운 것 — ‘관련 자료’가 아니라 ‘주장을 지지하는 이유’를 배치한다

W4 p.58~64의 여섯 축은 책임을 묻는 방식, 특별예방, 일반예방, 학교생활·사회복귀와 자유 제한, 치료 제공과 지속 여건, 치료 불참·반복 위반 대응이다. W2 p.47~48과 W3 p.59~61도 앞 자료를 같은 질문 아래 서로 다른 주장으로 회수한다.

### 8-1. 주장과 근거만으로 명료하게 쓴다

학생에게 보이는 기본 라벨은 `주장 / 근거` 또는 기존 덱의 `주장 / 근거·이유`다. `논리적 이유 / 규범적 근거 / 한정`을 별도 화면 영역으로 계속 늘리지 않는다.

근거는 연구결과뿐 아니라 법령, 판례, 이론, 개념, 가치규범, 논리적인 이유일 수 있다. 모든 칸에 논문을 한 편씩 억지로 붙이지 않는다. 실증근거가 없는 규범적 논증을 검증된 효과처럼 제시하지 않되, 자료가 없다는 설명이 정작 논증을 덮지 않게 한다.

### 8-2. 우선순위의 주장인지 확인한다

다음 문장만으로는 치료 또는 형사처벌의 우선성이 나오지 않는다.

| 문장 | 직접 뒷받침하는 내용 | 처리 |
|---|---|---|
| 사법기관 접촉 후 전문기관으로 연계할 수 있다 | 치료 필요의 발견·의뢰 기회 | 실행조건에 두거나 왜 처벌보다 먼저여야 하는지 실제 이유를 보태라 |
| 모든 청소년이 같은 수준의 치료를 필요로 하지는 않는다 | 치료 강도의 개별화 | 곧바로 형사처벌 기본의 근거로 놓지 마라 |
| 치료와 재활교육을 형사재판에서도 병행할 수 있다 | 병행 가능성 | 처벌 우선의 단독 근거가 아니라 주장의 보조 설명으로 사용하라 |
| 프로그램 완수율이 낮다 | 전달·참여·완료 문제 | 상대 정책이 더 효과적이라는 결론으로 바꾸지 마라 |
| 구금 뒤 교육·성인기 결과가 불리했다 | 특정 구금의 부담 | ‘구금 연구’라는 이유로 형사처벌을 지지하는 칸에 넣지 마라 |
| 일부 사용사례에서 판매·유통 가담이 있었다 | 사용과 다른 행위의 중첩 | 사용자 일반의 높은 판매 확률로 바꾸지 마라 |

한 근거를 같은 글자 그대로 상대 칸에도 넣을 수 있다면 ‘입장의 근거’보다 공통 조건일 수 있다. 필요한 연결 이유를 쓰거나 공통 조건·앞 단원으로 돌린다.

### 8-3. 열 제목의 일관성과 논리의 정확성을 함께 지킨다

4주차에서 사용자가 선택한 두 열의 이름은 `치료·재활 우선 / 형사처벌 우선`이다. 같은 단원 안에서 의미가 계속 바뀌지 않게 한다. 다만 열 제목을 통일하려고 단순한 서비스 운영자료를 형사처벌 우선의 증거로 강제로 바꾸지 않는다.

일반적인 논제 설계에서 ‘A를 우선해야 한다’의 부정이 언제나 ‘B를 우선해야 한다’만을 뜻하는 것도 아니다. 대표 입장 두 개를 대조하는 화면과 가능한 정책선택 전체를 구분한다. 어느 입장을 쓰든 기본원칙·적용대상·예외를 일관되게 설명한다.

### 8-4. 근거의 비대칭은 허용하되 잘못된 비교는 금지한다

**논거 비교표**에서는 한쪽이 실증연구를, 다른 쪽이 책임·비례·규범에 관한 이유를 제시할 수 있다. 이는 강제적으로 같은 수준의 실험논문을 맞추어야 한다는 뜻이 아니다.

반면 **효과 수치 비교표**에서 한쪽의 프로그램 목표와 다른 쪽의 실제 관찰결과를 같은 측정치로 배치해서는 안 된다. 기존 ‘근거수준 대칭’ 규칙은 이 구분에 따라 적용한다.

### 8-5. 쟁점 수보다 독립된 판단 질문을 기준으로 한다

비용·기관·참여·사후관리 각각이 별도의 장은 될 수 있지만, 서로 같은 적용·실행 질문에 답한다면 별개의 최종 쟁점을 만들 필요는 없다. 반대로 자료가 없다는 이유만으로 중요한 규범적 쟁점을 삭제하지 않는다. ‘4개’는 이번 강의의 선택이지 모든 강의의 의무 개수가 아니다.

## 9. 중복을 줄이면서 설명을 충분히 남기는 법

중복은 같은 연구명·제도명의 재등장 자체가 아니라 **같은 질문에 같은 정보로 다시 답하는 것**이다.

| 재등장 | 유지할 수 있는 다른 역할 |
|---|---|
| W3 p.6 / p.23 처리경로 | 첫 소개 / 초기 선별경로라는 새 초점 |
| W4 p.11 / p.33 수강명령 | 법적 성격·시간·대상 / 청소년이 실제 연습하는 활동 |
| W4 p.21 / p.31 / p.47 가족·또래 | 실제 사용 경험 / 관계에 관한 연구 / 생활환경을 바꾸는 치료 구성 |
| W4 p.36 / p.45 JDTC | 대상 선정 / 특정 연구의 실제 비교경로 |
| W4 p.35 / p.61 참여·완수 | 세부 전달결과 / 적용·실행을 판단하는 압축 근거 |

새 역할 없이 정의·자료·해석을 다시 반복하면 합치거나 줄인다. W4 p.28~29 석방 설명, p.49~52 수료·지속성의 반복처럼 남은 중복은 좋은 패턴으로 승격하지 않는다.

한 화면의 근거는 중요한 이유 2개를 기본으로 하고 필요한 경우 짧은 3번째 이유를 둔다. 이는 글자 수 상한이 아니라 읽는 부담을 조절하는 기본값이다. ‘추상어 3줄’보다 ‘이유가 이해되는 2문장’이 낫다. 낱말을 늘어놓는 압축도, 모든 자료를 보존하려는 과밀도 피한다.

## 10. 국내 자료를 먼저 충분히 조사한 뒤 국외 자료로 보완한다

2026-09-21 사용자 지시로 새로 확정된 조사 순서다. 세 덱이 실제로 어떤 순서로 웹 검색되었는지를 추정한 결론은 아니다.

> 기존 파일 확인 → 국내 법·통계·정부발표·정책자료·논문·보고서·보도·기사를 충분히 조사 → 국내 자료로 확인한 점과 남는 질문 정리 → 그 질문에 맞춰 국외 법·사례·연구 조사

상세 절차와 자료대장 양식은 `../DOMESTIC_FIRST_RESEARCH_PROTOCOL.md`를 따른다. 국내 기사·현장취재를 충분히 찾지 않고 유명한 외국 실험부터 채워 넣지 않는다. 다만 국내 자료라는 이유로 더 직접적이고 정확한 국외 원자료를 배척하지 않는다. **조사 순서, 자료의 신뢰성, 슬라이드에서의 비중은 서로 다른 판단**이다.

## 11. 미래 제작 순서

1. 최신 파일명·해시·실제 목차·페이지 수와 대화의 수정사항을 묶어 기준본을 확정한다.
2. 논제의 대상·행위·정책변화·비교대안·적용 단계를 적는다.
3. 국내 조사표를 먼저 작성한다. 법적 가능성, 실제 집행, 당사자 경험, 효과, 비용·권리의 각 역할을 점검한다.
4. 국내 조사 후 남은 질문마다 국외 자료를 찾고 왜 필요한지 기록한다.
5. 자료를 학습하는 순서로 목차를 짠다. 쟁점 목록을 그대로 목차로 쓰지 않는다.
6. 각 슬라이드가 새로 보태는 한 내용을 정하고 필요한 자료만 고른다.
7. 제도·사건·연구·통계의 성격에 맞는 화면 형식을 선택한다. 복잡하면 경위/판단, 개입/결과 등으로 분리한다.
8. 주장과 근거를 회수할 때 ‘무엇을 우선할 이유인가’를 점검한다. 자료가 없는 규범적 이유는 그 자체로 명확하게 쓴다.
9. 중복·연결·분모·범주·단위·그래프 데이터를 점검한다. 원문 확인 상태는 내부 자료대장에 남긴다.
10. 전체 렌더와 수정 전후 비교를 확인하고, 사용자 확정 여부에 맞는 상태로 등록한다. 강사가 특정 결론을 대신 내리지 않는다.
