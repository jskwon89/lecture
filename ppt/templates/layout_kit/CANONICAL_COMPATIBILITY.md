# layout_kit ↔ 현행 Canonical 호환성 메모

기준일: 2026-09-22

상태: **사용 가능 — 단, 현행 Canonical 우선**

이 키트는 그래프·표·흐름·글 부품의 재사용과 자동 배치를 위한 구현 라이브러리다. 현재 작업 기준은 항상 `ppt/current/README.md`에서 시작하며, `ppt/PPT_RULES.md`, `PPT_CONTENT_RULES.md`, `PPT_WORKFLOW.md`가 키트보다 우선한다.

## 그대로 사용할 수 있는 부분

- `Box`, `split_h`, `split_v`를 통한 영역 분할
- 글·표·그래프·흐름의 26개 사용자 호출 부품
- 예시 장 19종 + 혼합 예시 M1~M3의 조합 아이디어
- 영역 부족 로그
- 겹선 제거
- 묶음 막대의 폭 기반 연도축 축약
- 행 높이 계산·정렬 보조

## 현행 Canonical과 충돌하여 자동 정답으로 쓰지 않는 부분

1. **색·글자 크기** — `design.py`의 일부 값이 `PPT_RULES.md` v1.5와 다르다. 최종본에서는 Canonical 값을 우선한다.
2. **자동 글자 축소** — `fit.py`는 마지막 수단으로 0.5pt 축소를 허용한다. 현행 원칙은 공간이 부족하면 장 분할을 우선하므로, 축소가 발생하면 로그를 확인하고 Canonical 허용 크기인지 별도 감사한다.
3. **행 본문 세로정렬** — `row_table()`은 본문을 행 가운데에 둔다. 현행 Canonical의 역할별 위쪽 기준과 충돌하는 경우 최종본에서 Canonical을 따른다.
4. **인용 표기 위치** — `frame()`은 연구자·사건번호를 제목 뒤 또는 밴드에 둔다. 현행 문서에서 정한 사건번호·출처 배치 규칙과 충돌하면 Canonical을 따른다.

## 실제 제작 시 순서

1. `ppt/current/README.md`를 먼저 읽는다.
2. `layout_kit/COMPONENTS.md`에서 필요한 부품을 고른다.
3. `layout_kit/examples.py` 또는 예시 덱에서 가장 가까운 조합을 고른다.
4. 키트로 초안을 생성한다.
5. `PPT_RULES.md`의 색·타이포·정렬·출처 규칙으로 최종 보정한다.
6. `check_spacing.py` 등 기존 QA를 그대로 수행한다.
7. 충돌을 해결하기 위해 키트 자체를 수정했다면 `CHANGELOG.md`에 남긴다.

## 부품 수 표기

- 사용자 호출 부품: **26종** = 글 11 + 표 3 + 그래프 7 + 흐름 5
- `frame`, `Box`, 화면 분할, closing 등 골격 도구까지 포함하여 handoff에서는 ‘27종’으로 부른다.
