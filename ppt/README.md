# PPT 제작 기준 — READ FIRST

이 디렉터리는 경찰대학 「범죄·공공안전세미나Ⅱ」를 포함한 강의 PPT의 **공통 제작 기준과 최종 참조본**을 관리한다.

## 작업 시작 순서

PPT 구성안·대본·실제 PPT를 만들기 전에 반드시 다음 순서로 확인한다.

1. `ppt/PPT_RULES.md` — **최우선 제작 규칙**
2. `ppt/PPT_WORKFLOW.md` — 자료조사 → 구성안 → 제작 → 검수 절차
3. `ppt/references/REFERENCE_INDEX.md` — 해당 작업에 가장 가까운 최종 참조본
4. 해당 주차의 최신 논제·목차·사용자 지시
5. 실제 원자료·법령·논문·보고서

현재 대화에서 사용자가 명시적으로 지시한 사항이 이 문서와 충돌하면 **현재 사용자 지시가 우선**한다. 충돌이 반복되면 규칙 문서를 갱신한다.

## 핵심 원칙

- PPT는 **대본 없이 화면만 보아도 핵심 내용을 이해할 수 있게** 작성한다.
- 제목·밴드·본문·한정문은 서로 다른 역할을 갖는다.
- 연구·사례·정책은 추상적으로 요약하지 말고 **대상·구성·작동방식·비교·결과·범위**가 드러나게 쓴다.
- 연구 슬라이드는 초록이나 2차 요약만 보고 만들지 않는다. 가능한 한 원문 전체를 읽고 실제 처우와 비교조건을 확인한다.
- 최종 참조본은 디자인과 정보위계를 참고하되, 잘못된 내용까지 복제하지 않는다.

## 디렉터리

- `PPT_RULES.md` — 콘텐츠·제목·화면 작성 규칙
- `PPT_WORKFLOW.md` — 작업 절차와 QA
- `references/` — 최종본·기준본을 찾기 위한 인덱스
- `finals/` — 확정된 PPT/PDF/대본의 보관 규칙
- `CHANGELOG.md` — 규칙 변경 이력

> 이 디렉터리를 사용하는 작업자는 새 PPT 안을 제시하기 전에 이 README와 `PPT_RULES.md`를 먼저 읽는다.
