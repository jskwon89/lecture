# PPT 제작 기준 — READ FIRST

이 디렉터리는 경찰대학 「범죄·공공안전세미나Ⅱ」를 포함한 강의 PPT의 **Canonical 제작규칙·원문 소스·제작도구·최종 참조본**을 관리한다.

## 작업 시작 순서

PPT 구성안·대본·실제 PPT를 만들기 전에 반드시 다음 순서로 확인한다.

1. `ppt/PPT_RULES.md` — **최우선 Canonical 제작 규칙**
2. `ppt/PPT_WORKFLOW.md` — 자료조사 → 구성안 → 제작 → 검수 절차
3. `ppt/RULE_SOURCE_MAP.md` — 원문 소스와 supersede 관계
4. `ppt/references/REFERENCE_INDEX.md` — 해당 작업에 가장 가까운 최종·성숙 참조본
5. 해당 주차의 최신 논제·목차·사용자 지시
6. 실제 원자료·법령·논문·보고서

현재 대화에서 사용자가 명시적으로 지시한 사항이 Canonical과 충돌하면 **현재 사용자 지시가 우선**한다. 반복되는 변경은 `PPT_RULES.md`와 `CHANGELOG.md`에 반영한다.

## 핵심 원칙

- PPT는 **대본 없이 화면만 보아도 핵심 내용을 이해할 수 있게** 작성한다.
- 제목은 설명문을 길게 욱여넣지 말고 **그 장을 구별하는 핵심을 간결한 표제형으로** 쓴다.
- 문맥상 자명한 대상·조건은 제목에서 반복하지 않는다.
- 주체가 필요하면 실제 행위의 주체만 쓴다. 연구자가 만든 조건을 제도 자체가 한 것처럼 쓰지 않는다.
- 연구·사례·정책은 추상적으로 요약하지 말고 **대상·구성·작동방식·비교·결과·범위**가 드러나게 쓴다.
- 연구 슬라이드는 초록이나 2차 요약만 보고 만들지 않는다. 가능한 한 원문 전체를 확인한다.
- 대상·비교집단·결과처럼 위계가 다른 정보를 같은 급의 열에 병렬로 놓지 않는다.
- 한 장이 과밀하면 글자를 줄이지 말고 장을 나눈다.
- 최종 참조본은 디자인과 정보위계를 참고하되, 사실·수치·문구를 자동으로 정답 취급하지 않는다.
