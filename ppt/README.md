# PPT 제작 기준 — READ FIRST

갱신: 2026-09-23
이 디렉터리는 경찰대학 「범죄·공공안전세미나Ⅱ」를 포함한 강의 PPT의 **Canonical 제작규칙·원문 소스·제작도구·최종 참조본**을 관리한다.

## 작업 시작 순서

PPT 구성안·대본·실제 PPT를 만들기 전에 반드시 다음 순서로 확인한다.

00. **`ppt/AGENTS.md` — 모든 에이전트 공통 작업 방식(저장소 받기, 폰트, 산출물 전달, 커밋 규칙, 역할 분담).**
0. **`ppt/current/README.md` — 현재 적용 규칙만 모은 진입점. 여기서 시작한다.**
1. `ppt/PPT_RULES.md` — 현행 Canonical v1.7 전문·디자인·QA 규칙
2. `ppt/PPT_CONTENT_RULES.md` — 이후 사용자 지시를 반영한 **필수 콘텐츠·조사 추가규칙**
3. `ppt/PPT_WORKFLOW.md` — 국내 자료조사 → 국외 보완 → 구성안 → 제작 → 검수 절차
4. `ppt/RULE_SOURCE_MAP.md` — 원문 소스와 적용·supersede 관계
5. `ppt/references/REFERENCE_INDEX.md` — 해당 작업에 가장 가까운 최종·성숙 참조본
6. **새 주차 콘텐츠 설계 시** `ppt/references/COMPLETED_DECK_PATTERN_W2_W3_W4_20260921.md`
7. **자료 조사·보강 시** `ppt/DOMESTIC_FIRST_RESEARCH_PROTOCOL.md`
8. **신규 주차·전면 재구성·대규모 보강 시** `ppt/WEEK_RESEARCH_COVERAGE_TEMPLATE.md`를 복제해 12개 자료유형 + 통계 5축을 전수점검하고 PASS
9. **논제 정합성 중간감사 시** `ppt/PROPOSITION_ALIGNMENT_AUDIT_TEMPLATE.md` — 목차 전/후, 각 단원 후, 전체 초안 후 반복
10. 해당 주차의 최신 논제·목차·사용자 지시. 기존 덱 보강이면 현재 PPT를 먼저 읽고 유지/수정/재구성/신설/보충 이동으로 분류한다.
11. `ppt/references/completed/`에서 가장 가까운 실제 완성 PPTX 1~2개를 구조 캘리브레이션용으로 확인한다.
12. 실제 원자료·법령·논문·보고서·정부발표·보도·기사

현재 사용자의 명시적 지시가 우선한다. `PPT_RULES.md` v1.7은 승인된 행 글자 크기·본문 배치·칩 미사용을 반영한다. 나머지 기존 전문과 수치 규칙은 보존하고, 2026-09-23까지의 콘텐츠·조사 지시는 `PPT_CONTENT_RULES.md`와 `PPT_WORKFLOW.md`에서 추가 적용한다. 충돌·변경 범위는 `RULE_SOURCE_MAP.md`와 `CHANGELOG.md`에 기록한다. 추가규칙을 생략하고 예전 원문 소스만으로 제작하지 않는다.

## 핵심 원칙

- **국내 자료·보도·기사·정부발표자료를 먼저 충분히 조사하고, 확인한 점과 남는 질문을 정리한 뒤 국외 자료를 조사한다.**
- **목차를 짜기 전에 논제와 직접 관련된 주요 공개논의와 사법판단을 먼저 찾는다.** 토론회·공청회·숙의/공론화·경청회·공식 의견수렴·권고/회신뿐 아니라 **대법원·각급 법원 판결문/결정문과 헌법재판소 결정문을 필수로 선행 검색**하고, 실제 입장·근거·법리·권리부담을 추출한다. 공개논의 맵과 판례/헌재결정 맵이 모두 없으면 신규·대규모 작업의 목차를 최종 승인하지 않는다.
- **신규 주차는 12개 필수 자료유형과 공식통계 5축을 전수점검하고 `WEEK_RESEARCH_COVERAGE_TEMPLATE.md`가 PASS 되기 전에는 목차 최종 승인·페이지 구성·PPT 제작을 시작하지 않는다.**
- **자료가 많아져도 논제가 변형되지 않도록 `PROPOSITION_ALIGNMENT_AUDIT_TEMPLATE.md`를 목차 전·후, 각 대단원 후, 전체 초안 후 반복 적용한다. OUT OF SCOPE는 삭제·보충 이동하고, INDIRECT는 연결이유와 한계를 명시한다.**
- PPT는 **대본 없이 화면만 보아도 핵심 내용을 이해할 수 있게** 작성한다. 사례·법령·통계·연구에서 주체·행위·대상·조건·결과가 모호하게 축약되면 SCRIPT-HIDDEN TEST에서 HOLD하며, 대본으로 그 모호함을 보충하지 않는다.
- 제목은 설명문을 길게 욱여넣지 말고 **그 장을 구별하는 핵심을 간결한 표제형으로** 쓴다.
- 문맥상 자명한 대상·조건은 제목에서 반복하지 않는다.
- 주체가 필요하면 실제 행위의 주체만 쓴다. 연구자가 만든 조건을 제도 자체가 한 것처럼 쓰지 않는다.
- 연구·사례·정책은 추상적으로 요약하지 말고 **대상·구성·작동방식·비교·결과·범위**가 드러나게 쓴다.
- 연구 슬라이드는 초록이나 2차 요약만 보고 만들지 않는다. 가능한 한 원문 전체를 확인한다.
- 국내 보도·기사·인터뷰는 실제 경위와 운영 문제를 보여주는 핵심 자료로 조사하되, 보도와 판결·원표의 확인 수준을 구별한다.
- 대상·비교집단·결과처럼 위계가 다른 정보를 같은 급의 열에 병렬로 놓지 않는다.
- 주장에는 그 우선순위를 실제로 지지하는 근거를 붙인다. 연구뿐 아니라 이론·규범·개념적 이유도 근거가 될 수 있다.
- 논거 비교에서 양쪽 연구 개수를 억지로 맞추지 않는다. 효과 수치 비교에서는 측정치의 비교 가능성을 확인한다.
- 한 장이 과밀하면 글자를 줄이지 말고 장을 나눈다. 단원 수·쟁점 수·슬라이드 수를 구별한다.
- 그래프는 원표의 범주·분모·단위를 보존한다. 미확인 값을 0으로 표시하거나 항목을 임의 합산하지 않는다.
- 최종 참조본은 디자인과 정보위계를 참고하되, 사실·수치·문구를 자동으로 정답 취급하지 않는다.
- 강사는 특정 입장의 최종 결론을 대신 내리지 않는다.
