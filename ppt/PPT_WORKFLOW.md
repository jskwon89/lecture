# PPT 작업 절차

이 절차는 구성안 작성부터 최종 PPT 납품까지 적용한다.

## 1. 시작 전

반드시 다음을 먼저 읽는다.

1. `ppt/README.md`
2. `ppt/PPT_RULES.md`
3. `ppt/references/REFERENCE_INDEX.md`
4. 해당 주차의 최신 논제·목차·직전 확정사항

## 2. 자료 조사

연구·보고서·사례를 사용할 때는 먼저 원문을 확보하고 다음을 메모한다.

- 대상
- 시점·지역
- 개입·처우
- 비교조건
- 기간·강도
- 결과지표
- 핵심 수치
- 수치의 통계적 의미
- 한계
- 오늘 논제와의 직접성

논문 초록만으로 연구 슬라이드를 확정하지 않는다.

## 3. PPT 구성안

실제 PPT를 만들기 전에 페이지별 구성안을 먼저 작성한다.

각 장에는 최소한 다음을 적는다.

- 제목
- 상단 밴드
- 화면 배치
- 화면에 실제로 들어갈 문구
- 핵심 수치와 단위
- 하단 결론 또는 한정
- 앞뒤 장 연결
- 대본에서 추가할 설명
- 출처와 확인 상태

구성안 단계에서 한 장이 과밀하면 바로 두 장으로 나눈다.

## 4. 제목 QA

제목을 확정하기 전에 다음 순서로 줄인다.

1. 이 장의 핵심내용 한 문장 작성
2. 문맥상 자명한 대상 삭제
3. 연구자명·표본수·방법론 삭제
4. 실제 주체가 꼭 필요하면 맨 앞에 배치
5. 행위·차이·결과 중 이 장을 구별하는 핵심만 남김
6. 명사구·표제형으로 압축

## 5. 연구 슬라이드 QA

특히 다음 오류를 막는다.

- 연구대상과 비교집단을 같은 급의 열로 배치
- 제도 정의 없이 약어부터 제시
- `통상처리`라고만 쓰고 실제 처우 생략
- 결과를 연구방법보다 뒤로 숨김
- %와 %p 혼동
- hazard를 단순 재범률로 설명
- 한 지역·하위집단 결과를 전체 연구 결과처럼 표기
- 마약 소지 연구를 투약·사용 처벌 연구처럼 연결
- 비교집단도 치료를 받았는데 `처벌 vs 치료`로 단순화

## 6. 제작

구성안 승인 후 실제 PPT를 만든다.

- 가장 가까운 최종 참조본의 정보위계와 디자인 언어를 우선 참고한다.
- 글자를 줄여 한 장에 우겨 넣기보다 장을 나눈다.
- 화면 문구와 대본을 함께 갱신한다.

## 7. 렌더 QA

최종본 전에는 반드시 전체 PPT를 PDF/이미지로 렌더해 확인한다.

- 제목 줄바꿈
- 글자 크기
- 여백
- 정렬
- 도형 겹침
- 하단 공백
- 각주
- 페이지 간 스타일 일관성
- 화면만 보았을 때 이해 가능한지

자동검사만으로 완료 판정하지 않는다.

## 8. 최종본 등록

확정본은 `ppt/finals/` 규칙에 따라 저장하고 `ppt/references/REFERENCE_INDEX.md`에 추가한다.

최종본을 새 작업의 참조로 쓸 때는 **버전과 날짜를 명시**한다.
