## 2. 국내 조사를 먼저 충분히 수행하라

- 국내 법·통계·연구·보고서·정부발표·보도·기사·현장취재를 우선 최대한 조사하라.
- 국내 자료로 확인한 점과 남은 질문을 기록한 뒤 국외 자료를 조사하라.
- 상세 절차와 조사 대장은 `DOMESTIC_FIRST_RESEARCH_PROTOCOL.md`를 따른다.
- 국내 자료가 없다는 주장은 실제 검색 범위와 확인 결과를 근거로 하라. 검색 실패·원문 접근 실패를 자료 부재로 바꾸지 마라.
- 조사 순서와 근거의 질을 구별하라. 국내 자료를 먼저 찾되 더 직접적인 국외 근거를 배척하지 마라.

### 2-1. 필수 자료유형 전수점검 하드게이트

- 신규 주차·전면 재구성·대규모 보강은 `WEEK_RESEARCH_COVERAGE_TEMPLATE.md`의 12개 영역을 모두 실제로 확인한 뒤 진행한다.
- 12개 영역은 **논제·범위 / 법령·절차 / 공식통계 / 실제 국내 사건·보도 / 실제 운영·서비스 / 국내 연구·보고서 / 효과·결과 연구 / 권리·부담 / 비용·자원·실행가능성 / 국내 정책대안·기관 의견 / 해외 비교 / 근거 공백·불확실성**이다.
- 모든 영역을 PPT 본편에 넣을 필요는 없지만, 검색·검토 없이 빠뜨릴 수는 없다. 제외할 때는 `해당 없음` 또는 `사용하지 않음`의 이유를 기록한다.
- `자료 없음`은 상태값으로 쓰지 않는다. `검색했으나 직접자료 미확인`, `접근 실패`, `분리집계 없음`처럼 실제 확인 결과를 적는다.
- **공식통계는 별도 하드게이트**다. 모든 정책·범죄 주차에서 ① 규모 ② 추이 ③ 대상 특성 ④ 처리결과 ⑤ 서비스 이용·운영의 다섯 축을 각각 확인한다.
- 통계는 사람 수·사건 수·활동 건수·복수응답·비율, 기간, 분모, 연령기준, 기관별 집계단계를 구분한다. 서로 다른 단계의 통계를 같은 코호트처럼 결합하지 않는다.
- 12개 영역과 통계 5축 점검 뒤 **자료→목차 사상표**를 작성하고, 그 표가 완성되기 전에는 목차 최종 승인·페이지별 구성안·PPT 제작을 시작하지 않는다.
- 실제 사례가 필요한 경우 국내 실제 사건·판례·공식 사례·지원사례를 먼저 찾는다. **사용자가 명시적으로 허용하지 않는 한 강의용 가상사례를 새로 만들지 않는다.**
- 직접 효과근거가 없으면 간접자료를 효과의 증거로 승격시키지 말고, 그 공백 자체를 종합 판단 자료로 남긴다.
## 3. 목차·쟁점·슬라이드의 수를 구별하라

- 목차는 논제에 답하기 위해 자료를 학습하는 순서로 구성하라.
- 쟁점은 논제에 대한 판단이 달라지는 질문으로 구성하라. 같은 운영 문제의 세부항목마다 별도 쟁점을 만들지 마라.
- 복잡한 쟁점은 두 장으로 나누어도 된다. 쟁점 수를 줄이기 위해 화면을 과밀하게 만들지 마라.
- 4주차 최종본은 여섯 쟁점(책임 / 특별예방 / 일반예방 / 학교생활·사회복귀와 자유 제한 / 치료 제공·지속 / 불참·반복 위반 대응)을 사용한다. 다른 주차의 쟁점 개수·경제성 독립 여부를 자동 결정하지 마라.

## 4. 한 화면이 새로 설명하는 관계와 기억목표를 정하라

- 제목은 해당 장의 핵심을 간결하게 요약하라. 자명한 대상, 연구방법, 표본수, 진행 지시를 자동으로 제목에 넣지 마라.
- 처음 등장한 제도·약어는 한글 명칭과 실제 하는 일을 먼저 설명하라.
- `누가 / 누구에게 / 어떤 조건에서 / 무엇을 하고 / 무엇이 달라졌는가`를 필요한 만큼 구체화하라.
- 대상·비교집단·결과를 같은 급으로 배열하지 마라. 실제 비교축만 같은 위계에 놓아라.
- **화면을 단순 speaking cue로 만들지 마라.** 대본이 없어도 학생이 제목·핵심 사실·작동방식·결과·논제와의 관계를 기본적으로 이해할 수 있어야 한다.
- 페이지 제작 전에 **한 문장 기억목표**를 확정하라. 그 문장을 보여주는 최소 정보만 화면에 두고, 사례·맥락·반론·질문 대응은 대본에서 보완하라.
- 한 장의 질문과 역할을 확정한 뒤 최소한의 자료를 선택하라. 자료가 많다는 이유로 정의·방법·결과·한계·종합을 한 화면에 모두 넣지 마라.

## 5. 사법경로·실제 개입·논제상 입장을 구별하라

- 법적 절차와 처분의 이름, 실제 교육·치료·감독 내용, 그 처우를 우선하자는 입장은 서로 다른 분류다.
- 감독·검사·프로그램 참여 의무가 있다는 이유만으로 형사처벌 우선으로 분류하지 마라.
- 형벌이 아니라는 이유만으로 모든 보호처분을 치료우선으로 분류하지 마라. 실제 처분과 개입내용을 확인하라.
- 치료+감독 결합형 연구를 치료만 또는 형사처벌만의 효과로 배분하지 마라.
- 처리경로 분기와 시간순 진행, 개입 강도의 순위를 혼동하는 화살표를 사용하지 마라.

## 6. 주장에는 그 주장을 지지하는 근거를 붙여라

- ‘치료가 필요하다’와 ‘형사처벌보다 치료를 우선해야 한다’를 구별하라. ‘처벌도 가능하다’와 ‘처벌을 우선해야 한다’도 구별하라.
- 근거는 실증연구, 법령·판례, 이론·개념, 가치규범, 논리적인 이유를 모두 포함할 수 있다.
- 각 칸에 연구를 같은 수만큼 강제로 붙이지 마라. 경험적 자료가 없다는 이유만으로 규범적 주장을 배제하지 마라.
- 학생에게 보이는 구조는 원칙적으로 `주장 / 근거` 또는 `주장 / 근거·이유`로 하라. ‘논리적 이유’, ‘한정’ 같은 새 영역을 불필요하게 늘리지 마라.
- 연구가 어느 입장을 입증했다고 과장하지 마라. 구체적 결과와 정책 주장 사이에 필요한 이유를 짧고 명확한 문장으로 연결하라.
- 근거가 양쪽에 똑같이 성립하면 공통 기준·실행조건일 수 있다. 열 제목을 맞추려고 억지로 한 입장의 증거로 배치하지 마라.
- 책임·일반예방·권리 등 규범적 근거와 효과 연구는 함께 쓸 수 있다. 강사는 특정 결론을 대신 내리지 마라.

## 7. 비교표의 대칭을 정확하게 적용하라

- **효과 수치표:** 같은 대상·지표·기간·분모인지 확인하라. 프로그램의 목표와 실제 관찰결과를 같은 수치 비교로 제시하지 마라.
- **논거 비교표:** 한쪽이 연구결과를, 다른 쪽이 이론·가치규범을 근거로 제시할 수 있다. 같은 종류의 논문을 맞추는 것이 대칭의 뜻은 아니다.
- ‘A 우선’에 동의하지 않는다고 모두 같은 ‘B 우선’ 입장이라고 간주하지 마라. 선택한 대표 입장의 의미·대상·예외를 명확히 하라.
- ‘치료필요가 서로 다름’, ‘낮은 완수율’, ‘비용 증가’는 곧바로 형사처벌 우선의 증거가 아니다. 그것이 어떤 적용·자원배분 판단을 지지하는지 써라.

## 8. 결과의 범위는 수치와 문장 안에 담아라

- 표본·분모·기간·비교경로를 숫자 가까이에 제시하라. 필수 정보까지 모두 각주로 내리지 마라.
- 운영 안내, 실제 참여, 완료, 행동 변화, 비용을 서로 다른 지표로 제시하라.
- 일부 사례를 발생확률로, 유의하지 않은 차이를 ‘효과 없음이 입증됨’으로, 종료 뒤 우위 미확인을 ‘치료효과가 중단됨’으로 바꾸지 마라.
- 자료의 범위와 확인 상태는 자료대장·노트에 남겨라. 본문은 실질적 결과와 논거가 중심이 되게 하라. 일반적인 단서가 핵심 설명을 덮지 않게 하라.

## 9. 그래프는 데이터의 범주·단위를 보존해 그려라

- 그래프 요청에는 실제 막대·선·축·수치가 있는 그래프로 답하라. 숫자 텍스트 상자만 만든 뒤 그래프라고 하지 마라.
- 범주별 원래 이름·분모·기간을 유지하라. 미확인 값은 0으로 채우지 마라.
- 복수응답 항목이나 겹칠 수 있는 범주를 근거 없이 합산하지 마라.
- 조사대상·문항이 다르면 별도 패널을 우선 검토하라. 한 그래프에 놓기 위해 임의로 범주를 일치시키지 마라.
- 축·범례·직접 수치 라벨·단위·본문 설명을 대조하라. 퍼센트 값의 입력 단위와 표시 서식을 확인하라.
- 기존 W4 청소년/성인 비교 그래프는 합산·0값·출처의 재확인 전에는 검증된 수치 참조본으로 재사용하지 마라.

## 10. 분량·본편·보충을 완성본에 맞춰 운영하라

- 실제 완성본의 본편은 W2 50장, W3 62장, W4 64장이지만 이를 최소·최대 장수로 해석하지 마라.
- 장수보다 대본과 실제 발화시간으로 90~100분 단독 운영 가능성을 확인하라.
- 자료조사 단계부터 **본편 필수 / 본편 확장 / 대본에서 언급 / 보충 자료 / 사용하지 않음**으로 분류하라.
- 종합·학생 판단 구간은 중간 본문을 채우기 전에 4~7장 안팎을 먼저 예약하고, 시간 부족 시에도 남긴다.
- W3처럼 질문대응·간접연구·추가 판례를 보충으로 분리할 수 있다.
- 같은 내용을 잘게 나누어 장수를 늘리거나, 여러 기능을 한 장에 넣어 장수를 줄이지 마라.

## 11. 중복·표시본·전달상태를 점검하라

- 동일 자료의 재등장에는 새 역할이 있어야 한다. 제도 소개→실제 활동→효과→논거 회수는 가능하지만 같은 정의를 계속 반복하지 마라.
- 본문 재배열 뒤 목차·키커·NEXT·노트의 연결을 함께 바꿔라.
- 최하단 각주 제거 요청은 요청한 표시 영역에만 적용하라. 기존 내용·디자인을 임의로 추가 변경하지 마라.
- 각주 제거와 별개로 출처를 원본·노트·자료대장에 추적 가능하게 보존하라. 실제 보존 상태를 확인하고 보고하라.
- 화면에 새로 넣지 않은 자료, 아직 원문을 확인하지 않은 수치, 제안만 된 수정은 완료로 표시하지 마라.
