## 0. 사용 원칙

이 문서는 **자료를 빠뜨리지 않기 위한 제작 전 하드게이트**다. 사용자의 명시적 예외지시가 없는 한, 아래 12개 필수 검토영역과 통계 5축을 실제로 확인하고 상태를 기록하기 전에는 다음 단계로 넘어가지 않는다.

- 금지: 목차 최종 승인
- 금지: 페이지별 구성안 확정
- 금지: PPT 제작 시작
- 허용: 조사계획, 자료대장, 임시 메모, 출처 검증

모든 항목을 PPT에 넣으라는 뜻은 아니다. **모든 항목을 실제로 검색·검토한 뒤, 넣지 않는 경우에도 이유를 남긴다.**

자료 상태는 아래 네 값 가운데 하나만 쓴다.

- **확보** — 원자료·원표·원문 또는 사용 가능한 직접 자료를 확인
- **검색했으나 직접자료 미확인** — 실제 검색 범위는 기록했지만 직접 근거를 찾지 못함
- **접근 실패** — 자료의 존재 또는 후보는 확인했으나 원문·원표에 접근하지 못함
- **해당 없음** — 논제상 해당 영역이 중요하지 않음. 사유 필수

‘자료 없음’은 상태값으로 쓰지 않는다. 검색 실패·접근 실패·분리통계 부재를 자료 부재로 바꾸지 않는다.

배치 상태는 아래 다섯 값 가운데 하나만 쓴다.

- **본편 필수**
- **본편 확장**
- **대본에서 언급**
- **보충 자료**
- **사용하지 않음**

강의용 가상사례는 사용자가 명시적으로 허용하지 않는 한 새로 만들지 않는다. 실제 사례가 필요하면 국내 실제 사건·판례·지원사례·공식 사례기록을 먼저 찾는다.
