## 2. 감사 목표

### A. 누락

- 기존 소스에 있던 강제규칙이 보존되어 있는가.
- 화면 문안·제목·밴드·행·필수 적용범위·출처·대본·노트·QA 중 빠진 영역이 있는가.
- 법령·판례·통계·여론조사·연구·사례별 검증 규칙이 유지되는가.
- 새 콘텐츠규칙·국내 우선 조사·통합 분석이 README와 WORKFLOW 필독 목록에 실제 연결되어 있는가.

### B. 충돌

- 원문 11.1판과 현재 규칙의 충돌·supersede 범위가 추적되는가.
- 제목은 간결한 표제형 핵심내용, 자명한 대상 생략, 실제 주체 원칙을 유지하는가.
- 연구자가 만든 조건을 제도 자체가 수행한 것처럼 쓰지 않는가.
- 최신 규칙을 과거 ‘주체를 반드시 맨 앞’ 규칙으로 되돌리지 않는가.
- ‘근거수준 대칭’을 양쪽에 똑같은 종류의 실험논문을 붙이라는 규칙으로 오독하지 않는가.
- 본문 정확성은 유지하면서도 ‘논리적 이유/한정’ 등 불필요한 라벨을 다시 늘리지 않는가.

### C. 실제 제작 가능성

- 기본 Canonical의 디자인 숫자와 `pptlib.py`, `rowfit.py`, `layout.py`, `check_spacing.py`가 일치하는가.
- 승인 골격 유형과 도구 좌표로 실제 덱을 만들 수 있는가. 원본 골격 PPTX가 있으면 추가 대조한다.
- 폰트 파일을 Git에 배포하지 않고 검수 환경에 Pretendard Regular/Bold를 설치하는 방식이 유지되는가.

### D. 콘텐츠 품질

- 화면만으로 주체·조건·작동·결과·논제 관계를 이해할 수 있는가.
- 대상/비교/결과의 위계를 구분하고 비교집단의 실제 처우를 설명하는가.
- 관련 있다는 이유만으로 자료를 주장 아래 넣지 않고, 왜 해당 우선순위를 지지하는지 확인하는가.
- 이론·규범·개념적 이유를 근거로 허용하면서 실증효과처럼 포장하지 않는가.
- 운영 안내·참여·완료·효과·비용 지표를 분리하는가.
- 같은 자료가 재등장할 때 새 역할이 있는가.
- 강사가 최종 정책결론을 대신 선택하지 않는가.

### E. 국내 우선 조사

- 국내 법·통계·정부발표·연구·보도·기사·현장 자료를 먼저 충분히 조사하도록 되어 있는가.
- 국내 조사 결과와 공백을 기록한 뒤 국외 자료를 찾는 게이트가 있는가.
- 국내 원문을 보지 않고 ‘없음’으로 처리하거나 외국 자료로 바로 대체하는 것을 막는가.
- 기사·정부 발표의 지위와 원자료 확인 범위를 구별하는가.
- 국내 우선이라는 순서를 근거의 질이나 국내효과의 우월성으로 오해하지 않는가.

### F. 통계·그래프

- %/%p/hazard/OR 등의 의미와 입력·표시 단위가 일치하는가.
- 원표 없는 범주 합산·미확인0값·서로 다른 응답대상의 직접 비교를 막는가.
- 그래프 요청에 실제 축·막대·수치 라벨을 제공하는가.
- W4 별도 비교 그래프의 DATA QA HOLD를 해소하지 않은 채 승인본으로 재사용하지 않는가.

### G. 참조 덱·현재 상태

- W2 50쪽, W3 85쪽, W4 61쪽의 관찰 범위와 실제 파일이 맞는가.
- 현재 W4 7단원을 과거37쪽 handoff의 6단원으로 되돌리지 않는가.
- 61쪽에 없는 비용 상세장·최종 답 작성장을 이미 있는 것처럼 설명하지 않는가.
- 참조 덱의 오래된 문구·오류·좌표를 규칙으로 승격하지 않는가.
- 하단 각주 제거는 표시본 요구이며 출처 관리의 폐기가 아님을 구별하는가.
