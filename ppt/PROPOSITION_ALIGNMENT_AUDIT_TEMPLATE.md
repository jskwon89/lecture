기준일: 2026-10-06  
상태: REQUIRED MID-PRODUCTION AND PRE-DELIVERY HARD GATE  
적용: 논제 정합성 중간감사 + 모든 구성안·대본·PPT의 첫 제출 및 수정 범위 내용 검수

## 0. 목적

자료가 많아질수록 강의가 ‘관련 있는 이야기’의 모음으로 퍼지는 것을 막는다. 이 감사는 **자료·단원·슬라이드가 정식 논제의 어떤 판단에 필요한지**를 반복 확인한다.

첫 제출 전에는 **페이지의 실제 설명이 처음 듣는 학생에게도 성립하는지**까지 검사한다. 실행 절차·제출 조건은 `PPT_WORKFLOW.md` §4-4, 내용 기준은 `PPT_CONTENT_RULES.md` §2-3·§4-1·§4-11·§7을 따른다. 단원 일부·한 페이지 작업은 해당 범위에 필요한 절만 적용하고 전체 목차를 다시 감사하지 않는다. 이미 구성안에 있는 근거는 위치를 연결해 중복 작성을 줄인다.

사용자의 명시적 예외가 없는 한 아래 시점에서 반드시 수행한다.

1. **자료조사 PASS 후, 목차 최종 승인 전**
2. **목차 승인 후, 페이지별 구성안 확정 전**
3. **각 대단원 구성안이 끝날 때마다**
4. **전체 초안이 완성된 뒤, 디자인·렌더 QA 전**
5. **새 연구·사례·통계가 대량 추가되거나 단원 순서를 크게 바꾼 뒤**
6. **전체 장·단원 초안을 처음 전달하기 전 및 수정본 전달 전** — 제출 범위의 모든 페이지에 §4·§4-1 적용. ‘초안’이라는 이유로 생략하지 않음

감사가 HOLD이면 다음 제작단계로 넘어가지 않는다.

## 2. 정합성 등급

각 자료·슬라이드·단원은 다음 중 하나로 판정한다.

- **DIRECT** — 논제의 정책선택·법적 문턱·효과·부담·실행조건 중 하나를 직접 판단하게 함
- **NECESSARY BASELINE** — 직접 결론을 주지는 않지만 뒤의 직접자료를 이해하기 위해 반드시 필요한 기준선·정의·절차
- **INDIRECT** — 대상·국가·처우·결과가 달라 간접적으로만 도움. 연결이유와 한계를 명시해야 함
- **OUT OF SCOPE** — 흥미롭거나 관련은 있지만 논제 판단에 필요한 기능을 설명할 수 없음. 원칙적으로 삭제·보충 이동

`INDIRECT`와 `OUT OF SCOPE`를 `DIRECT`처럼 표현하지 않는다.

## 4-1. 페이지별 설명 검수 — 첫 제출 전 전수 작성

아래 카드를 제출 범위의 페이지마다 작성하거나 같은 필드가 있는 구성안 위치에 연결한다. 표지·구분 장도 포함한다. **대본을 가린 화면 검수 → 낭독 설명 → 앞뒤 연결** 순서로 읽고 기록한다. 단순한 PASS 체크 대신 실제 문구·확인 위치·판단 이유를 적는다. 적용되지 않는 항목은 이유와 함께 `해당 없음`으로 표시한다.

### p.__ / 페이지 ID / 제목

| 검수 항목 | 실제 문구·확인 위치·판단 근거 | PASS / HOLD / 해당 없음 |
|---|---|---|
| 논제 기여·분량 | §4의 역할·등급·배치 결정 연결. 이 페이지에서 새로 배우는 사실·관계 |  |
| 화면 단독 이해 | 누가 누구에게 무엇을 하는지, 필요한 조건·비교·결과를 설명하는 실제 화면 문구 |  |
| 새 개념·추상 표현 | 처음 나오는 용어의 설명 위치. ‘대응·참여·지원’의 구체적 대상과 활동 |  |
| 프로그램·연구 대상 | 적용 대상 / 활동 참여자 / 측정 대상의 구별. 같은 집단이면 그 근거 |  |
| 비교·결과의 범위 | 비교 항목의 수준·관계, 실제 비교집단, 측정지표·시점·분모 및 결과 문장과 원자료 위치 |  |
| 낭독 설명 | 페이지 질문에 답하는 사실·이유의 문장. 핵심 누락·반복·설명 없는 용어 점검 |  |
| 앞뒤 연결 | 앞 페이지 마지막 설명 → 이번 첫 설명 / 이번 마지막 설명 → 다음 첫 설명. 이어지는 내용과 새 질문 |  |
| 전달본 대응 | 실제 화면·노트·구성안의 대응 위치. 변경한 문구·번호·참조가 함께 반영되었는지 |  |

- **발견한 누락·수정:** 원문구 → 수정문구 또는 변경 위치. 수정할 내용이 없으면 검수 근거를 남기고 ‘수정 없음’.
- **같은 문제의 점검 범위·결과:** 확인한 페이지 ID와 수정/해당 없음. 이번 검수에서 공통 문제가 발견되지 않았으면 그 상태 기록.
- **미확인 사실·남은 조치:** 확인할 원자료·파일과 해결 방향. 화면에 없는 핵심 설명을 대본만으로 PASS시키지 않음.
- **페이지 판정:** PASS / HOLD / 미검토. 적용 항목에 HOLD가 있거나 검수 근거가 비어 있으면 페이지 PASS 불가.

판정은 §4의 자료 역할과 함께 읽는다. 설명이 구체적이어도 논제 기여가 없으면 본편 배치를 다시 검토하고, 논제에 필요해도 설명이 모호하면 문구를 고친다. 이 카드는 제작 기록이며 학생용 화면·낭독 대본에 넣지 않는다.

## 5. 논제 변형·대상 이동 감사

다음 변형이 생기면 즉시 HOLD한다.

- **대상 이동** — 논제의 청소년/사건이 아닌 다른 집단 자료가 본편의 핵심 결론을 대신함
- **행위 이동** — 논제가 묻는 행위 대신 인접 범죄·피해를 중심으로 바뀜
- **비교대안 이동** — 원래 A vs B가 어느새 A vs 방치 또는 A vs 전혀 다른 처우로 바뀜
- **결과 이동** — 피해감소를 묻다가 이용실적·만족도·기관목표로 효과를 대신함
- **법적 질문 이동** — 법적 요건·권한의 문제를 도덕적 필요성이나 위험성만으로 대신함
- **시점 이동** — 사전개입 논제인데 사후 범죄자·피해자 자료가 직접결론을 대신함

변형이 의도적이고 필요한 경우 `INDIRECT`로 낮추고 연결이유·한계를 적는다.

## 7. 판정

**PASS**
- 모든 단원과 본편 슬라이드가 DIRECT / NECESSARY BASELINE / 정당화된 INDIRECT 중 하나
- OUT OF SCOPE가 본편에 남아 있지 않음
- 논제의 대상·비교대안·결과·시점이 유지됨
- 최종 종합에서 직접근거와 간접근거·공백을 구분함

**HOLD**
- 단원 역할을 논제와 연결해 설명할 수 없음
- 위험·문제의 크기만으로 특정 개입의 우선성을 결론냄
- 비교대안이 원래 논제와 달라짐
- 간접자료가 직접효과처럼 사용됨
- 자료가 많다는 이유만으로 논제와 무관한 구간이 본편에 남음

**최종 판정:** PASS / HOLD

**누락된 페이지 ID, 빈 근거, 미해결 HOLD 또는 미검토가 있으면 내용 검수 전체 PASS로 표시하지 않는다.** 수정 후 판정은 실제 전달본에 대해 갱신한다. 자료·설명 내용 검수와 렌더·파일 QA, 사용자의 최종 확정은 서로 다른 상태로 보고한다. 이 집계는 기계적인 체크만으로 설명 품질을 인증하는 자동검사가 아니다.



## 8. 2026-10-07 실제 독해 근거 보강

`SCREEN_FIRST_REVIEW.md`를 적용한다. 각 페이지에 처음 듣는 학생의 질문, 화면에 있는 답의 실제 인용, 그 인용으로 이해되는 주체·행위·조건·이유·결과, 풀어 쓴 지시어·추상어, 행·열 관계, 낭독 인용, 직전·다음 연결, 수정 전 문제·수정 내용·최종 재독 결과를 기록한다. 해당 없음은 자료유형에 따른 이유가 필요하다.

기존 구성안 일치·대본에 있음·이전 PASS를 근거로 화면을 통과시키지 않는다. 사용자 질문으로 기본 설명 누락이 확인되면 이전 PASS를 철회하고 같은 누락을 제출 범위 전체에서 재점검한다. 기존 기록에는 대체본을 연결한다. 콘텐츠 파일 해시와 페이지 ID를 기록하고, 자동 점검은 구조 검증임을 명시한다.
