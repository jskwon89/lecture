상태: REQUIRED MID-PRODUCTION HARD GATE  
적용: 신규 주차·전면 재구성·대규모 보강 및 이후 주요 수정

## 0. 목적

자료가 많아질수록 강의가 ‘관련 있는 이야기’의 모음으로 퍼지는 것을 막는다. 이 감사는 **자료·단원·슬라이드가 정식 논제의 어떤 판단에 필요한지**를 반복 확인한다.

사용자의 명시적 예외가 없는 한 아래 시점에서 반드시 수행한다.

1. **자료조사 PASS 후, 목차 최종 승인 전**
2. **목차 승인 후, 페이지별 구성안 확정 전**
3. **각 대단원 구성안이 끝날 때마다**
4. **전체 초안이 완성된 뒤, 디자인·렌더 QA 전**
5. **새 연구·사례·통계가 대량 추가되거나 단원 순서를 크게 바꾼 뒤**

감사가 HOLD이면 다음 제작단계로 넘어가지 않는다.

## 2. 정합성 등급

각 자료·슬라이드·단원은 다음 중 하나로 판정한다.

- **DIRECT** — 논제의 정책선택·법적 문턱·효과·부담·실행조건 중 하나를 직접 판단하게 함
- **NECESSARY BASELINE** — 직접 결론을 주지는 않지만 뒤의 직접자료를 이해하기 위해 반드시 필요한 기준선·정의·절차
- **INDIRECT** — 대상·국가·처우·결과가 달라 간접적으로만 도움. 연결이유와 한계를 명시해야 함
- **OUT OF SCOPE** — 흥미롭거나 관련은 있지만 논제 판단에 필요한 기능을 설명할 수 없음. 원칙적으로 삭제·보충 이동

`INDIRECT`와 `OUT OF SCOPE`를 `DIRECT`처럼 표현하지 않는다.

## 3. 단원 정합성 감사

| 단원 | 이 단원이 답하는 한 문장 질문 | 논제의 어느 부분에 필요한가 | 등급 | 이 단원을 빼면 무엇이 판단 불가능해지는가 | 과잉·이탈 위험 | 조치 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  | 유지 / 축소 / 재배치 / 보충 / 삭제 |

### 단원 PASS 질문

- 단원명이 단순 자료유형이 아니라 **논제를 이해하는 단계**인가?
- 이 단원의 마지막에서 다음 단원이 왜 필요한지 설명할 수 있는가?
- ‘문제가 크다/위험하다’는 자료만 있고 **왜 이 특정 정책수단이어야 하는지**가 빠지지 않았는가?
- 현행 제도·대안·효과·부담 중 어느 기능인지 분명한가?
- 단원이 흥미로운 사례·해외비교 때문에 비대해지지 않았는가?

## 4. 슬라이드 정합성 감사

| p. | 제목 | 한 문장 기억목표 | 논제 역할 | 등급 | 이 자료로 말할 수 없는 것 | 조치 |
|---:|---|---|---|---|---|---|
|  |  |  | 기준선 / 규모 / 작동 / 효과 / 부담 / 대안 / 실행조건 / 공백 |  |  |  |

### 슬라이드 PASS 질문

1. 이 장이 답하는 질문을 한 문장으로 말할 수 있는가?
2. 그 질문이 정식 논제의 판단을 실제로 바꿀 수 있는가?
3. 대상·비교대안·결과가 논제와 같은가? 다르면 왜 간접근거인지 표시했는가?
4. ‘보호 필요’, ‘위험 존재’, ‘서비스 존재’를 곧바로 특정 정책의 우선성·효과로 바꾸지 않았는가?
5. 사례 하나를 빈도·인과·정책효과의 증거로 사용하지 않았는가?
6. 통계의 분모·기간·단위가 논제 대상과 다를 때 그 차이가 화면에서 보이는가?
7. 이 장이 없어도 최종 논증이 전혀 약해지지 않는다면 본편에 둘 이유가 있는가?

## 5. 논제 변형·대상 이동 감사

다음 변형이 생기면 즉시 HOLD한다.

- **대상 이동** — 논제의 청소년/사건이 아닌 다른 집단 자료가 본편의 핵심 결론을 대신함
- **행위 이동** — 논제가 묻는 행위 대신 인접 범죄·피해를 중심으로 바뀜
- **비교대안 이동** — 원래 A vs B가 어느새 A vs 방치 또는 A vs 전혀 다른 처우로 바뀜
- **결과 이동** — 피해감소를 묻다가 이용실적·만족도·기관목표로 효과를 대신함
- **법적 질문 이동** — 법적 요건·권한의 문제를 도덕적 필요성이나 위험성만으로 대신함
- **시점 이동** — 사전개입 논제인데 사후 범죄자·피해자 자료가 직접결론을 대신함

변형이 의도적이고 필요한 경우 `INDIRECT`로 낮추고 연결이유·한계를 적는다.

## 6. 전체 구성 감사

| 확인항목 | YES / NO | 메모 |
|---|---|---|
| 정식 논제가 표지·목차·종합에서 동일한 의미로 유지된다 |  |  |
| 각 단원은 논제 판단에 필요한 서로 다른 기능을 맡는다 |  |  |
| 기준선→실제 작동→문제 위치→대안/비교→경험자료→부담/한계→종합 흐름이 유지된다 |  |  |
| 통계는 규모·추이·대상특성·처리결과·서비스 운영을 필요에 따라 다루되 효과와 혼동하지 않는다 |  |  |
| 실제 사건은 제도작동·맥락을 보여주며 일반화되지 않는다 |  |  |
| 해외자료는 국내 공백을 보완하며 한국의 직접효과처럼 쓰이지 않는다 |  |  |
| 직접근거가 없으면 그 공백을 종합에서 명시한다 |  |  |
| 본편의 모든 INDIRECT 자료에는 필요한 이유와 한계가 있다 |  |  |
| OUT OF SCOPE 자료는 삭제 또는 보충으로 이동했다 |  |  |
| 마지막 쟁점지도·논거는 앞 본편에서 실제 다룬 자료만 회수한다 |  |  |
| 강사가 자료보다 앞서 정책결론을 정해놓고 자료를 배열하지 않는다 |  |  |

## 7. 판정

**PASS**
- 모든 단원과 본편 슬라이드가 DIRECT / NECESSARY BASELINE / 정당화된 INDIRECT 중 하나
- OUT OF SCOPE가 본편에 남아 있지 않음
- 논제의 대상·비교대안·결과·시점이 유지됨
- 최종 종합에서 직접근거와 간접근거·공백을 구분함

**HOLD**
- 단원 역할을 논제와 연결해 설명할 수 없음
- 위험·문제의 크기만으로 특정 개입의 우선성을 결론냄
- 비교대안이 원래 논제와 달라짐
- 간접자료가 직접효과처럼 사용됨
- 자료가 많다는 이유만으로 논제와 무관한 구간이 본편에 남음

**최종 판정:** PASS / HOLD
