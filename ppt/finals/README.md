# 최종본 보관 규칙

확정된 강의 산출물만 이 디렉터리에 둔다.

## 권장 구조

```
finals/
  w02_death_penalty/
  w03_delinquent_age/
  w04_youth_drugs/
  ...
```

각 폴더에는 필요에 따라 다음을 둔다.

- 최종 PPTX
- 최종 PDF
- 최종 강의대본 DOCX 또는 PDF
- 필요 시 제작 스크립트
- `README.md` — 확정 버전·날짜·참조 포인트

## 파일명

중간 작업본과 최종본을 혼동하지 않게 한다.

예:
- `w04_youth_drugs_final_vXX.pptx`
- `w04_youth_drugs_final_vXX.pdf`
- `w04_youth_drugs_script_final_vXX.docx`

## 참조본 승격

1. 사용자가 최종 확정한 버전만 FINAL로 표시한다.
2. `references/REFERENCE_INDEX.md`에 경로와 날짜를 등록한다.
3. 이후 PPT 작업자는 가장 가까운 FINAL을 디자인·정보위계 기준으로 확인한다.
4. 더 최신 FINAL이 생기면 기존 파일을 삭제하지 말고 superseded 상태를 기록한다.

## 공개 저장소 주의

현재 `jskwon89/lecture` 저장소는 public이다. 개인·민감정보, 비공개 강의자료, 배포권이 없는 원문 PDF·폰트 파일은 올리지 않는다.
